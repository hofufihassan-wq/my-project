الأساس المعتمد: `3d4575aeae16c22b6932a6bac5b18a7a4f9cca37`، من `feat/simulator-final-glass-workbench`. فُحص الكود والوثائق الفعلية وواجهات Chromium. لا تعديل لتصميم الرئيسية/القاموس/المحاكي ولا تغيير على صفحات الأساس.

## الأدلة وحدود نسبتها

- `results.json`: جولة كاملة لـ25 مصطلح CSS و64 مثيلًا لأدوات التحكم عبر المصطلحات؛ أدوات مشتركة تتكرر بين مصطلحين مثل Grid/gap وFlex/alignment وcolor/background. 21 أداة إدخال/اختيار فريدة فعلية، إضافة إلى الأزرار.
- سياق CSS الأول حمّل نسخة index/app من الأساس قبل إصلاح الجذر؛ الصور الأصلية ذات suffix `-clean` ثم `-red-circle` توثق المشكلة الفعلية. الدائرة طبقة توضيح مؤقتة في سياق الأدلة، لا تغييرًا للموقع.
- السياقات الجديدة لاختبار الصفحات والتجاوب حُمّلت بعد تطبيق إصلاحات HTML الصغيرة؛ لذلك ليست لقطات بصرية قبل الإصلاح. لم يظهر تجاوز أفقي للمستند في16 حالة: الرئيسية/القاموس/المحاكي/الإعدادات ×1440/768/390/320. لا تعني لقطة ثابتة أن جميع حالات التحرير/التفاعل تعمل.
- `video/439a6cb50bddafb1bbd4f60ac9094bd3.webm`: تسجيل Chromium الفعلي لجولة CSS بما فيها تغير الأدوات ودوائر العيوب. مسار ffmpeg النظامي رُبط محليًا لأداة التسجيل؛ لا صوت للموقع في هذا الفيديو ولا صور تخيلية.
- `control-inventory.csv`: كل مثيل تحكم وقيم الاختبار (الحد الأدنى والوسط والأقصى لكل range، كل خيارات select، كل زر/لون متاح). الوحدات التي توفرها الواجهة فقط اختُبرت: px و% وdeg ومقياس عددي ونسب أبعاد؛ لا إدخال وحدات حرة أو دعم rem/vw عام يمكن ادعاؤه.
- بعض مقارنات computedStyle الأولية التقطت بداية انتقال CSS، حتى بعد تغيير inline style؛ احتُفظ بالتسجيل الخام ولم تُصنف الفروق المؤقتة عيوبًا. `fix-initial-attempt.*` يحتفظ بمحاولة غير ناجحة بسبب الانتظار الزمني؛ `fix-verification.json` النهائي يستخدم انتظار شرط الخاصية نفسه. `after/` يعيد جميع الأدوات مع انتظار إطارَي رسم؛ ثم `after-stable/` يعيدها بانتظار تطابق القيمة النهائية فعليًا. `replay-summary.json` يفصل خصائص transition/animation التي يوقفها harness في النسخة المعاد تطبيقها؛ بيانات تلك الخصائص لا تقارن بالأصل لأنها تغييرات أداة الاختبار، مع إبقاء الملاحظات الخام. الاختبار المستقل للحركات موجود في fix-verification.json.

الواجهة صريحة بشأن نقص صفحات التنظيم. لا تُعد الأزرار التي تفتح تلك الصفحات معطلة؛ وظيفة إدارتها غير منفذة. قوائم تصنيفات القاموس والدروس على الجوال قابلة للتمرير الأفقي، ولذلك وجود زر خارج viewport في القياس الخام لا يثبت أنه غير قابل للوصول. كذلك محتويات details المغلقة ليست أزرارًا مرئية رغم إمكان إرجاع إحداثيات لبعض الأبناء. لم أعتبر هذه الحالات عيوبًا مؤكدة.

## تحسينات مقترحة بلا تنفيذ تلقائي

1. أولوية متوسطة لاحقة: مواصفة صغيرة لمولد CSS يربط التحكم بالنص القابل للنسخ وإعادة التطبيق، مع عزل الناتج عن تنسيق الموقع.
2. أولوية متوسطة لاحقة: توسيع الاستوديوهات السبعة الناقصة والخصائص المتعلقة بالخطوط والوحدات، بعد اعتماد نطاق التطوير.
3. أولوية منخفضة: تخفيف عبارات دعائية مثل مقارنة فلاتر CSS ببرامج Photoshop؛ وصف الخاصية المحددة أدق للمتعلم.
4. أولوية منخفضة: خطة وصول كاملة لأسماء أزرار الألوان والتنقل بلوحة المفاتيح وقراءة screen reader والتباين عبر الثيمات؛ فحص21 عنصرًا لا يغطي كل الوصول.
5. أولوية متوسطة: حفظ إعدادات الثيم ضمن مراجعة مخطط بيانات معتمدة، لا ترحيل صامت أثناء التدقيق.

المراجع المناسبة للقواعد: MDN background-color، aspect-ratio، backdrop-filter، CSS Flexible Box Layout، CSS Grid Layout، animation وprefers-reduced-motion. الروابط الأصلية موجودة في بيانات المصطلحات؛ ليست مراجعة رسمية حديثة لجميع صفحات MDN عبر الشبكة. الاختبارات مباشرة في محرك Chromium.

التحقق النهائي لإعادة التطبيق: 409/409 ملاحظة خاصية CSS فعلية صالحة ومتطابقة في القيمة computed بعد الاستقرار. هذا يثبت إعادة تطبيق CSS inline المقروء من DOM، ولا ينشئ زر تصدير CSS أو يثبت صحة المثال الأصلي في محرر القاموس.
