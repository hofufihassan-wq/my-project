## ENGINE-01 — خلل متوسط، أُصلح

تعطّل تحرير تبويب JavaScript أو CSS لمصدر صحيح يحتوي `İ` (U+0130) قبل وسم الإغلاق. كان `scanBlocks` يبحث عن وسم الإغلاق داخل `source.toLowerCase()` ويطبق الفهرس على المصدر الأصلي؛ يتحول هذا المحرف إلى محرفين، فتتغير إزاحات UTF-16. مثال مثبت:

```html
<p>Unicode example: İ</p>
<script>console.log("ENGINE_UNICODE_OK")</script>
```

قبل الإصلاح يظهر «الكتلة غير مكتملة» ويصبح تبويب JS للقراءة فقط، ويتضمن النص المعروض `</script>` خطأً. الإصلاح في `simulator-beta.js`: مطابقة أسماء وسوم ASCII دون تحويل المصدر إلى lowercase، مع إبقاء الإزاحات في النص الأصلي. لا تغيير للمحتوى أو البيانات أو الواجهة.

- `audit_engine_unicode_test.cjs`: قبل الإصلاح **2/6** وبعده **6/6**. تشمل CSS وJS والمحتوى قبل الكتلة وداخلها، ووسم إغلاق uppercase وحدود `</scripted>` والمحافظة على النص المحيط.
- `audit_engine_browser.cjs`: تشغيل فعلي في Chromium **154.0.8037.57**. قبل الإصلاح أثبت منع التحرير، وبعده أثبت استخراج JS وإمكان تشغيله ووصول `ENGINE_UNICODE_OK` إلى Console.
- صورتا وفيديوهات حقيقية: `engine/before/unicode-editor.png` و`.webm`، و`engine/after/unicode-editor.png` و`.webm`. الدائرة الحمراء أضيفت كطبقة DOM موثقة فوق رسالة العطل الفعلية قبل التصوير؛ ليست صورة مولّدة. Playwright أنشأ كذلك ملف فيديو خامًا باسم آلي، وأُبقي دون حذف.

## تحقق مستقل من العزل والتوقف

`audit_engine_security_browser.cjs`، **3/3** في Chromium:

1. كود داخل إطار فعلي يحاول تعديل DOM الأب والوصول إلى localStorage؛ كلاهما يرفض بـSecurityError، مع بقاء `sandbox="allow-scripts"`.
2. رسالتان تحملان runId وlessonId الصحيحين من نافذة الأب ومن إطار آخر؛ لا تغيران الحالة أو السجل. هوية WindowProxy مطلوبة، وorigin=null وحده غير كاف.
3. مؤقت setInterval فعلي يرسل سجلات، ثم إيقاف من زر الواجهة؛ لا سجلات متأخرة ويصبح activeRun=null.

## حدود ومخاطر متبقية

- Sandbox يفصل صلاحيات DOM والتخزين، لكنه لا يضمن عزل جدولة المعالج: حلقة متزامنة لا نهائية قد تجمّد التبويب. لا ادعاء بضمان إيقافها. استبدال ذلك ببيئة تنفيذ أو بنية أخرى يحتاج قرارًا معماريًا.
- الإطار يسمح بتحميل شبكة وفق المتصفح؛ ليس بيئة منع تسريب شاملة. لا تحتوي البيئة الأساسية أسرارًا، ولا يحق وصفها كحاوية آمنة لتشغيل كود عدائي غير موثوق.
- DOM_SNAPSHOT محدود بالنصوص والعدادات المعلنة، وReady مجرد جاهزية. لا يُستنتج منه تنفيذ صحيح منطقيًا.
- ملفات الاسترجاع والتفضيلات تبقى في localStorage الخاص بالأصل؛ حدود المتصفح ومسح بيانات الموقع تظل تؤثر عليها. تصدير التقدم ضروري للاحتفاظ بنسخة خارج المتصفح.
- لا تضم هذه الجولة إصلاح الصوت الأحدث أو دمجه. الصوت يحتاج مراجعة مستقلة بالتسجيل الفعلي كما طلب المستخدم.
- لا Firefox أو WebKit في هذه الاختبارات، ولا تحقق من صحة جميع أشكال هجمات Web Platform. لا ادعاء أمان مطلق.
