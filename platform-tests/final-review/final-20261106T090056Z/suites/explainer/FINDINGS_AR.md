# مساحة «اشرح لي» المحلية

## ما نُفذ

- مكون Vue3 فعلي مستقل `vlex-explainer` في `learning-explainer.js`، وتنسيقه المعزول في `learning-explainer.css`. لا استدعاء لخدمة أو إضافة مكتبة.
- لصق HTML وCSS وJavaScript وVue SFC، واختيار اللغة، ثم «اشرح لي» يدويًا افتراضيًا. التحليل التلقائي اختياري650ms بعد توقف الكتابة، ويُوقف المؤقت أثناء IME. إعادة فتح المسودة لا تفعل التحليل التلقائي.
- لكل سطر مصدره الحقيقي ورقمه ووصف صيغته. كل جزء لغوي ظاهر زر يوضح الكلمة أو الرمز، لماذا يُستخدم، ومثالًا عند توفر معرفة محلية. غير المعروف يُعرض كجزء يحتاج سياقًا بدل اختراع معنى.
- ربط نصي لأسماء التعريفات والاستخدامات مع أرقام الأسطر؛ الشرح يصرح أنه ليس حل نطاقات أو قيم متغيرات فعلية. التعليقات والنصوص لا تنشئ تعريفات مزيفة.
- ربط المصطلحات المعروفة بمعرفاتها الأصلية عبر props `terms`، وإرسال `open-term(termId)` للأب للتنقل إلى القاموس.
- نطق تقريبي عربي للكلمات المعروفة، وزر نطق عبر Web Speech بعد ضغط المستخدم. يختار صوتًا إنجليزيًا محليًا (`localService`) فقط. إذا لم يوجد صوت، يعرض السبب ولا يدعي تشغيله. جودة النطق تتبع الصوت المثبت بالنظام؛ لم يُختبر صوت Windows فعلي هنا.
- حفظ المصدر واللغة في قسم `explainer` الخاص بـ`VLexLearningStore` إذا كان محملًا، دون تعديل مخطط VueLexicon القديم. الأحداث `draft-change(source)` متاحة للأب أيضًا.
- كل مصدر يظهر عبر Vue text interpolation وtextarea، لا `v-html` ولا eval ولا Function ولا تشغيل مصدر المستخدم في الأب. لا تشغّل هذه المساحة الكود أصلًا.
- الحدود واضحة:20,000 محرف و300 سطر و10,000 جزء في كل تحليل؛ النص الأكبر يرفض برسالة، لا يختصر المصدر ليبدو التحليل مكتملًا.

## الربط

حمّل Vue المحلي ثم `learning-store.js` و`learning-explainer.js` قبل تركيب تطبيق Vue. أضف stylesheet إلى head. المكون يضيف نفسه إلى `window.VLexPlatformComponents`:

```html
<vlex-explainer :terms="rawLexiconData" @open-term="openTermById" />
```

`props`: terms:Array وinitialCode:String. `window.VLexExplainer.analyze(source,language,terms)` متاح للتحقق المحلي وNode. قائمة اللغات: `html`, `css`, `javascript`, `vue`.

## حدود صريحة

هذا **محلل صياغة وكلمات محلي**، وليس مدرسًا بالذكاء الاصطناعي يفهم كل برنامج حر. لا يفحص صحة البرنامج ولا يثبت أثره، ولا يستنتج قيم المتغيرات أو نتائج الفروع أو يقرر صحة خوارزمية. أسماء متطابقة في نطاقات مختلفة قد ترتبط نصيًا بأول تعريف؛ الواجهة تصرح بذلك.

لا فصل دلالي كامل لـRegExp، قوالب template literals المتداخلة/متعددة الأسطر، التعبيرات داخل صفات Vue، ولا blocks متعددة اللغات على السطر نفسه. source strings وقيم الصفات تُشرح كوحدة نصية، لا كبرنامج داخلي مفكك. TypeScript غير مدعوم كفاحص أنواع. قد يوجد syntax غير صالح مع شرح رموز صحيح؛ إشعار الشرح ليس إثبات صحة syntax.

لم يُختبر قارئ شاشة فعلي أو كل محرك WebKit/Firefox أو كل أصوات أنظمة التشغيل. لم نقسّم ملفًا غير محدود من دون حد؛ للمشاريع الأكبر يشرح المتعلم مقطعًا محددًا. لا وعد بشرح كل كلمة حرة دلاليًا أو بلوغ الاحتراف عبر هذه الأداة وحدها.
