# لوحة اليوم وأدوات التنظيم المحلية

الملفات الجديدة فقط: `learning-dashboard.js` و`learning-dashboard.css`. لا تعديل للمحاكي أو `app.js` أو `index.html` من هذه المهمة الفرعية، ولا commit أو رفع أو نشر.

## التكامل

يضاف ملف JavaScript قبل إنشاء تطبيق Vue، ثم تُسجل عناصر `window.VLexPlatformComponents`:

- `<vlex-dashboard @navigate="openFoundation" @learn="openCourse" />` جزء مكمل للرئيسية الحالية، بلا استبدال تصميمها. `navigate` يعيد اسم القسم نصًا مثل `calendar` أو `kanban`، و`learn` يعيد `{}`.
- `<vlex-organizer :mode="foundationSection" @learn="openCourse" />` لأقسام `tasks` و`kanban` و`calendar` و`notes` و`projects`. زر تعلم المشروع يعيد `{id:'task-manager'}`. لا تشغيل كود تلقائي من هذه المكونات.
- يستعمل المخزن المشترك `VLexLearningStore.getSection/setSection/subscribe/status`. لا يقرأ أو يهاجر مفاتيح VueLexicon القديمة. تبقى أدوات تصدير/استيراد بيانات المنصة عند الجذر.

## ما يعمل فعليًا

- مهمة حقيقية بعنوان وتاريخ اختياري وحالة `todo/doing/done`، تعديل ونقل بين الأعمدة؛ لا لوحة Kanban زخرفية أو أعمدة بأعداد وهمية.
- أرشفة وإعادة كل سجل بدل الحذف النهائي. لا حذف لبيانات موجودة.
- مشاريع فعلية ووصف وربط المهمة بمشروع وتصفية مهامه؛ لا ادعاء تشغيل مشاريع متعددة الملفات.
- ملاحظات نصية متعددة الأسطر وتعديل وأرشفة، مع عرض escaped يمنع تنفيذ HTML الملصق.
- تقويم ميلادي شهري مع42 يومًا، تنقل بين الأشهر وتحديد يوم، موعد بعنوان وتاريخ ووقت محلي اختياري وملاحظة، وتعديل وأرشفة وإعادة.
- رئيسية مكملة: ساعة جهاز فعلية وتاريخ محلي ومهام اليوم والمتأخرة ومواعيد قادمة وأعداد مستمدة من سجلات المستخدم، والدروس المنجزة ومراجعاتها من قسم `course`.
- لا تكتب المكونات أي بيانات عند فتحها لمجرد تعبئة الشاشة. كل تعديل ناتج تفاعل صريح.
- حد عنوان180 حرفًا، نصوص12000، تحقق تاريخ/وقت وحالة. الأصل غير المقروء أو التخزين غير المتاح يعرض تحذيرًا، ولا يدعي حفظًا دائمًا ناجحًا.
- مؤقت الساعة والاشتراك ينظفان عند إلغاء تركيب المكون.

## المخطط المضاف للمخزن المشترك

| القسم | السجل |
|---|---|
| tasks | id,title,due,status,projectId,archived,createdAt,updatedAt |
| events | id,title,date,time,notes,archived,createdAt,updatedAt |
| notes | id,title,body,archived,createdAt,updatedAt |
| projects | id,title,description,archived,createdAt,updatedAt |

الأرشفة لا تمسح العلاقة بين المشروع والمهمة. التواريخ `YYYY-MM-DD` والأوقات `HH:mm` محلية، بلا تخزين منطقة زمنية أو مزامنة خادم.

## القيود

- هذه اختبارات مكون مستقل مع المخزن المشترك الحقيقي؛ يجب على الجذر إعادة اختبار التكامل داخل الموقع النهائي قبل وصفه جاهزًا.
- البيانات تبقى في هذا المتصفح وأصله. لا تنبيهات نظام أو بريد أو مزامنة أو حساب خارجي، والواجهة تصرح بذلك.
- Kanban يستخدم أدوات نقل صريحة بلوحة المفاتيح بدل سحب زخرفي؛ لا يدعي drag-and-drop.
- المشاريع تنظيم محلي للمهام ووصف المشروع، وليست مدير ملفات أو بيئة Nuxt/Vite.
- أعداد إنجاز الدروس تأتي من اختيار المتعلم وسجلاته، ولا تعني شهادة إتقان.
- لم يُختبر Windows أو Firefox أو WebKit فعليًا في هذه المهمة الفرعية.
