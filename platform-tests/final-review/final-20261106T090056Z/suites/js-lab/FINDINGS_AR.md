# مختبر JavaScript — التنفيذ والاختبارات

الفرع: `feat/vlex-personal-learning-platform`. المكون الجديد `vlex-js-lab` من `learning-js-lab.js` و`learning-js-lab.css`، دون تعديل المحاكي الأزرق أو كود التطبيق/الواجهة الرئيسيين من هذه المهمة.

## التنفيذ الفعلي

- المصدر يُحلل في التطبيق بواسطة `VueLexiconCompiler.babelParse` الموجود محليًا. لا eval أو Function لكود المستخدم في سياق التطبيق.
- iframe بـ`sandbox="allow-scripts"` فقط، ذو أصل opaque/null، ينشئ Blob Worker. أثبت probe.cjs تشغيل العامل بأصل null على Chromium.
- كود المستخدم ينفذ داخل دالة async في العامل المعزول، ويطبع Console ويرسل قيم المتغيرات التي قرأها فعلًا. لا تتبع مختلق من تحليل النص.
- يأخذ المحلل حدود التعليمات العليا من AST؛ لا يُقسم النص على الفاصلة المنقوطة أو نهاية السطر. التشغيل خطوة بخطوة يقف قبل كل تعليمة عليا، ثم يأخذ snapshot بعد اكتمالها. جسم if/for/function وحدة واحدة، وليس debugger لكل سطر داخلي.
- المتغيرات المراقبة أسماء مصرح بها في المستوى الأعلى، بما فيها destructuring. لا introspection كامل للإغلاقات أو المتغيرات داخل الدوال والحلقات. يعرض القيم الطويلة والكائنات والدوال باختصار محدود؛ قد تنفذ getters أثناء القراءة.
- iframe يوقف العامل عند تجاوز تنفيذ تعليمة مهلة2.5 ثانية. التوقف عند انتظار زر خطوة لا يستهلك المهلة. بعد انتهاء التعليمات العليا يسمح بمهلة إضافية2.5 ثانية للمؤقتات ثم ينهي العامل؛ انتهاء التعليمات لا يُسمى انتهاء جميع async tasks.
- زر الإيقاف ينهي العامل والإطار، وتشغيل جديد يبطل الرسائل القديمة. تغيير المصدر لا يشغله تلقائيًا؛ يُعلن أن النتائج قديمة إلى أن يطلب المستخدم التشغيل.
- CSP موروثة: connect-src none، وdefault-src none؛ أثبت الاختبار رفض fetch خارجي، دون تغيير جدار حماية الجهاز.
- بروتوكول التطبيق يشترط WindowProxy للإطار الحالي وrunId وبنية/حجم/عدد الحقول. عامل JavaScript لا يملك DOM أو parent أو localStorage. رسائل العامل الخام بلا nonce لا تدخل Console. هذا حد عزل وموثوقية إشارة، وليس ضمانًا عامًا لتشغيل كود عدائي أو تصحيح منطقي لكل برنامج.
- المصدر فقط يُحفظ ضمن `VLexLearningStore` قسم `jsLab: {source:string}`. لا تعديل لمفاتيح بيانات VueLexicon القديمة.
- حدث `practice` يمرر `{code}` إلى جسر المحاكي عند طلب المستخدم، لتجارب DOM/Vue. لا توصيل تلقائي أو تشغيل مصدر مستورد عند التحميل.

`node platform-tests/js-lab/browser.cjs`: **12/12**، خروج0 في Chromium حقيقي مع Vue والمحلل المحليين. البيانات الدقيقة في `results/browser.json` والسجل `browser.log`:

1. factorial بحلقة ودالة وif؛ الناتج240 وقيمة متغير فعلية.
2. توقف قبل الأثر، ثم قيم2 ثم5 من نفس دورة التنفيذ الحقيقية.
3. سلاسل تحوي ; ومصفوفة متعددة الأسطر وdestructuring دون تقطيع خاطئ.
4. خطأ صياغة وخطأ ReferenceError حقيقي.
5. حلقة while(true) تُنهى خلال أقل من5 ثوان ثم تجربة جديدة ناجحة، مع استجابة الصفحة.
6. مؤقت فعلي يتوقف عند زر الإيقاف ولا يلوث تشغيلًا جديدًا.
7. حلقة لا نهائية داخل callback متأخر تنتهي بمهلة المؤقتات دون تجميد الصفحة.
8. لا document/parent/localStorage في العامل، وfetch خارجي يُرفض بفعل CSP.
9. رفض رسائل مزورة من الأب وإطار آخر وعامل المستخدم بلا nonce.
10. نص `</script><img ...>` يبقى بيانات ولا يُنشئ عنصرًا في الأب.
11. تحرير الكود لا يشغله، ويحفظ النص بعد reload دون تشغيل تلقائي.
12. جسر المحاكي ينقل المصدر، وتجاوب390px لا يتجاوز عرض المستند.

## القيود الصريحة

- مختبر لغة JavaScript، لا DOM أو Vue أو npm أو import مشروع أو TypeScript. شبكة Worker مقفلة، وليست وسيلة لتعليم fetch لخادم حقيقي.
- التنفيذ داخل async function يختلف عن script عالمي: var لا ينشئ خاصية global، وthis/strict/global bindings ليست بالضرورة سياق window. هذا ظاهر في الواجهة؛ استخدم المحاكي عند احتياج متصفح DOM.
- لا يسمح await على المستوى الأعلى في المصدر الحالي؛ استخدم دالة async تستدعيها، مع حد نافذة async المذكور.
- لا يدعي مراقبة كل متغير أو تفسير كل سطر؛ AST يضمن حدود التعليمات، وقراءة القيمة تضمن المعلومة المرصودة فقط.
- اختبارات هذا المكون standalone بقالب اختبار واقعي؛ الجذر مسؤول عن اختبارات دمجه مع تخزين المنصة وقوائم التنقل. لا اختبار Windows فعلي أو Firefox/WebKit أو IME على نظام تشغيل حقيقي في هذه الحزمة.
- الاختبار يحفظ النص بعد reload؛ لا ندعي أن اختبار reload وحده يثبت بقاء ملفات profile بعد إغلاق نظام التشغيل.
