# مراجعة مستقلة لمخطط بيانات التعلّم المحلي

تاريخ التنفيذ: 4 نوفمبر 2026. النطاق: `learning-store.js` واختبارات `platform-tests/store/` فقط. لم تتغير مفاتيح بيانات VueLexicon القديمة، ولم يُنفّذ ترحيل أو نشر أو دمج.

## العيوب المثبتة والإصلاح

1. كان المدقق يقبل بنى غير متوافقة مع الواجهة؛ مثل `notes.body: {}`، و`tasks.projectId: {}`، و`course.answers: []`، وقيم غير نصية للمحررات. لم يكن وجود قسم من نوع كائن كافيًا للتحقق من حقوله الداخلية. أُضيف تحقق من أنواع الحقول المعروفة وبنى إجابات الدروس ومواعيد المراجعة والمسودات وقوائم فحص المشروع وسجل الإجابات وأدوات CSS. التاريخ يُفحص كتاريخ تقويمي حقيقي؛ القيم الفارغة أو الكاذبة ذات النوع الخاطئ لم تعد تتجاوز الفحص.
2. كان فشل `setSection` في التحقق من حمولة التعديل يعامل السجل الأصلي كأنه تالف ويحوّل الحفظ إلى الوضع المحمي. فُصل رفض التعديل عن فشل قراءة الأصل: يُرفض التعديل غير الصالح دون تغيير الحالة أو بايتات التخزين أو وضع الحفظ، ويمكن حفظ تعديل مصحح بعدها. فشل قراءة الأصل أو تلفه ما زال يحميه ويتيح تصدير التغييرات المؤقتة.
3. أُعيد إنتاج حد حجمي غير سليم: حالة حجمها **2,097,152 بايت** حُفظت بنجاح، لكن ملف تصديرها بلغ **2,097,241 بايت** ورفضه محلل الاستيراد نفسه. يُحسب الآن حجم غلاف النسخة الاحتياطية مع الحالة والقيم الافتراضية قبل قبول الحفظ. لا يُقص النص. يختبر الانحدار قبول نسخة كاملة حجمها **2,097,152 بايت** وإعادة قراءتها دون اختلاف.

القيم الافتراضية والأقسام الجزئية القديمة مقبولة: الملاحظة بلا `body`، والمهمة بلا طوابع زمنية، و`course` الذي يحتوي `completed` فقط، وCSS الذي يحتوي `css` فقط. تستكمل خرائط الدروس الافتراضية الناقصة. لا تُرفض معرفات دروس مستقبلية لمجرد أنها ليست في قائمة الدروس الحالية، وتبقى البيانات الوصفية الإضافية الآمنة محفوظة. لا يغير المخزن نصوص المستخدم لتجاوز الاختبارات.

## الأدلة والنتائج

| الفحص | النتيجة |
|---|---|
| اختبارات المخزن الأصلية `node platform-tests/store/run.cjs` | 13/13 ناجحة بعد الإصلاح |

| إعادة إنتاج خلل حد الحجم | الاختبار الجديد فشل؛ السجل `size-boundary-before.json` |

اختبار المتصفح يستخدم Vue والملفات الحقيقية للقاموس التنظيمي، والدروس، ومختبر CSS، ومختبر JavaScript، وشرح الكود، وليس بدائل مقلدة لها. جرى استيراد بيانات بالمخططات الفعلية، ثم فتح المكونات كلها، ورفض سبع حمولات غير صالحة دون تغير الحالة أو بايتات الأصل أو مفاتيح الاسترجاع. بقي النص المستورد غير منفذ. جرى تحديث الصفحة واستعادة النص الصحيح، ثم تحميل سجل مشوه والتحقق من الوضع المحمي ووجود الأصل ونسخة استرجاع مطابقة دون أخطاء JavaScript غير معالجة.

السجلات: `results.json`، و`schema-results.json`، و`schema-browser-results.json`، و`schema-browser.log`. الصورة الفعلية لحالة السجل المحمي: `protected-import-browser.png`.

## حدود التحقق

هذه اختبارات المخزن والمكونات الفعلية داخل صفحة اختبار محلية مستقلة، وليست بديلًا عن اختبار دمج واجهة الموقع كاملة. لم يختبر هذا الجزء Windows أو Firefox أو WebKit، ولم يدّع صحة شاملة لجميع البيانات التعليمية. أدوات CSS لها تحقق تفصيلي إضافي في مكون المختبر؛ المخزن يتحقق من أنواع إعداداتها والخيارات المعروفة، ولا يحكم على قصد CSS أو مخرجاته البصرية.
