# إصلاح قبول التعليقات — اكتُشف أثناء تسجيل المعاينة

المصحح كان يجتاز البيانات الوصفية leadingComments/trailingComments/innerComments الخاصة بمحلل Babel، فيعامل CommentLine/CommentBlock كتعليمات خارج نطاق الدعم. لذلك يمكن أن يرفض حلًا صحيحًا يبقي تعليق البداية.

الإصلاح يتجاوز حقول بيانات التعليقات فقط، كما يتجاوز loc/tokens، دون توسيع صلاحيات التنفيذ أو تغيير حالات التقييم. أُضيف اختبار وحدة وتعليقات سطرية وكتلية إلى فحص الحلول الصحيحة الفعلي في المتصفح.

النتائج بعد الإصلاح: 9/9 وحدة و21/21 متصفح، مع التحقق من الأصول 27/27. ملفات baseline تحفظ النتائج السابقة 8/8 و21/21 كما كانت عند b0b9491. لم نعد مصفوفة المنصة الثلاثين كاملة لهذه الإضافة المحدودة؛ نتيجتها السابقة وأسباب الإعادات محفوظة.

لا تغيير للتصميم أو المحاكي أو مخطط الحفظ أو بقية المناهج. الالتزامات الأربعة الأصلية رُفعت كما هي، دون إعادة كتابة تاريخها.
