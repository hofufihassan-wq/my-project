# إصلاح مصادر CSS التعليمية في القاموس

تاريخ الاختبار: 2026-11-06T08:58:21.698Z. الفرع أثناء العمل: `feat/vlex-personal-learning-platform`. مرجع العمل المحفوظ قبل هذه الإصلاحات: `55fab885d1eba6cb48313b407bd6d10432dd2297`. رقم commit التسليم النهائي يثبته المطوّر المسؤول بعد جمع الإصلاحات.

## النتيجة

اجتازت مصادر Vue الخمسة والعشرون لفئة CSS الاختبار الفعلي داخل مشغّل القاموس المعزول في Chromium: **25/25**. لم يُستخدم Ready وحده دليلًا؛ فُحصت القيم المحسوبة والأبعاد والتحويم والتركيز والنقر والتمرير والحركة وفق المفهوم. لم تظهر أخطاء في التطبيق الأب، ولم تتطلب الأمثلة طلبًا خارجيًا.

في الاختبار السابق للإصلاح كانت **25/25** مصادر تعرض قالبًا عامًا دون أي عنصر يطابق المحدد الأساسي للمفهوم. كانت قواعد كاملة متداخلة داخل `.target-element`، بينما العناصر المستهدفة غير موجودة. لا يعني ذلك أن كل CSS المتداخل مرفوض نحويًا في المتصفحات الحديثة؛ الخطأ المثبت هو عدم تطبيق العرض التعليمي المقصود.

## حدود التغيير

تحتوي [patches.json](patches.json) على المصدر قبل وبعد، والمعرّف الثابت، والحقل5، والسبب، والنتيجة المتوقعة، ومرجع MDN الموجود أصلًا. التغيير خاص بمصدر Vue لكل مصطلح؛ لم أغيّر المعرّفات أو أمثلة Vanilla أو التعريفات أو النسخ الاحتياطية أو المحاكي. أضيفت عناصر HTML حقيقية مع CSS محلي واضح بدل الاعتماد على Tailwind أو مكونات Nuxt غير المتاحة.

مثال scroll-behavior يستخدم زر Vue وref يستدعي scrollTo دون خيار سلاسة داخل JavaScript؛ تحدد CSS السلوك الناعم. استُبعد رابط fragment لأن srcdoc قد يحله نسبة إلى مستند الأب وينتقل بدل التمرير المحلي. يستخدم مثال cursor عنصر details أصليًا، وله فتح وإغلاق حقيقيان دون خدمة أو مكتبة وهمية.

## ما لا يثبته هذا التقرير

هذا تحقق من25 مصدر CSS بصيغة Vue على Chromium/Linux، وليس اعتمادًا لكل360 مصدر أو لكل تعريف أو لكل متصفح. لم يُشغّل Windows هنا. فحص filter وbackdrop-filter والتدرجات يعتمد على CSS المحسوب والعناصر/الخلفيات الفعلية والصور المرفقة؛ لا يوجد تحليل بكسل منفصل لكل هذه التأثيرات. جرى اختبار200ms/300ms من التحولات المقصودة، لا كل قيمة ممكنة يعدّلها المتعلم.

رُفعت للمطوّر المسؤول ملاحظة منفصلة عن values غير صالحة في نص justify-content القديم؛ أصلح الحقلين6 و14 إلى space-between وspace-around وspace-evenly وسجلها في `platform-tests/dictionary/css-syntax-corrections.json`. هذا التصحيح منفصل عن حزمة الحقل5 الموضحة هنا.
