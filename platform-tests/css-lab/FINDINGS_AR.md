# مختبر CSS التعليمي — تنفيذ واختبارات فعلية

تاريخ التحقق: 2026-11-04. هذا التقرير يخص المختبر الجديد المعزول، ولا يحكم على اكتمال بقية المنصة أو المحاكي.

## التنفيذ والتكامل

- الملفات: `learning-css-lab.js` و`learning-css-lab.css`.
- المكون المسجل: `vlex-css-lab` عبر `window.VLexPlatformComponents`، دون تعديل ملف التطبيق الرئيسي ضمن هذه المهمة الفرعية.
- الحفظ: قسم `cssLab` في `VLexLearningStore`، ويحفظ HTML وCSS وأدوات التحكم وخيار التحديث التلقائي. لا يستعمل مفاتيح بيانات القاموس أو يستبدل مسوداته.
- محرران حقيقيان ومعاينة HTML/CSS، وزر تطبيق يدوي، وخيار تحديث تلقائي، ونسخ CSS وتنزيله.
- القيم المولدة تكتب داخل القسم `VLEX-LAB:START` / `VLEX-LAB:END` فقط. النص الحر خارج هذا القسم يبقى كما هو. يستطيع المستخدم تعديل CSS كاملًا، ويطبق كما كتبه؛ تغيير أداة يعيد توليد القسم المدار ويشرح ذلك في الواجهة.
- لا تعديل لتصميم المحاكي، ولا حذف للمختبر القديم أو بياناته.

## أدوات التحكم المتاحة

| الأداة | الدعم الفعلي |
| --- | --- |
| margin، padding، font-size، width، height، gap، border-radius | وحدات px وrem و%، وحدود مختلفة مناسبة لكل وحدة، ورسالة رفض للقيمة غير الصالحة دون استبدال CSS السابق |
| الألوان | لون خلفية ولون نص بصيغة HEX |
| نوع التخطيط | flex وgrid وblock |
| اتجاه Flex | row وcolumn وrow-reverse وcolumn-reverse |
| التفاف Flex | wrap وnowrap وwrap-reverse |
| التوزيع | flex-start وcenter وflex-end وspace-between وspace-around وspace-evenly |
| المحاذاة | stretch وflex-start وcenter وflex-end وbaseline |
| Grid | عدد أعمدة صحيح من 1 إلى 6 |

كل الأدوات تستهدف `#lab-target` الموجود فعلًا في HTML الابتدائي، الذي يحتوي ثلاثة أبناء. القواعد الحرة الأقوى و`!important` تستطيع التغلب على الأدوات؛ ليست أداة قياس أو ضمانًا لصحة نية المستخدم. ارتفاع `%` يعتمد على ارتفاع الحاوي، وgap وخصائص المحاذاة تتأثر بنوع التخطيط. تبديل الوحدة يختار قيمة بداية مناسبة ولا يدعي تحويل القيمة السابقة حسابيًا.

## الاختبارات المنفذة

| الاختبار | النتيجة | الدليل |
| --- | --- | --- |
| فحص JavaScript | نجاح | `node --check learning-css-lab.js` |
| اختبارات المنطق وتوليد CSS | 46 من 46 | `unit.cjs` و`unit-results.json` و`unit.log` |
| Chromium حقيقي مع خادم مؤقت على 127.0.0.1 والمخزن المشترك الحقيقي | 38 من 38 | `browser.cjs` و`browser-results.json` و`browser.log` |

شملت اختبارات المتصفح جميع الأدوات، و21 تركيبًا من المقادير والوحدات (7 × 3)، مع الحد الأدنى وقيمة وسطية والحد الأعلى لكل تركيب. تحققت الاختبارات من CSS المكتوب، وقبول المتصفح للخاصية، والقيم المحسوبة داخل iframe، ومطابقة إعادة تطبيق القواعد على عنصر مماثل. اختبرت كل خيارات Flex والتخطيط، وGrid عند 1 و6 أعمدة، والألوان الفعلية.

اختُبر أيضًا:

- إبقاء CSS الحر خارج القسم المدار، وعدم تكرار القسم عند تعديلات متتالية.
- عدم تحديث المعاينة عند تعطيل التحديث التلقائي حتى الضغط على زر التطبيق.
- رفض قيمة padding سالبة مع إبقاء CSS السابق.
- رفض الحافظة: لا تظهر رسالة نجاح كاذبة عند فشل `clipboard.writeText`.
- تنزيل CSS ومطابقة بايتاته مع محرر CSS. نسخة الاختبار: `downloaded-lab.css`.
- إغلاق الصفحة وإعادة فتحها في سياق المتصفح نفسه وبقاء HTML وCSS مطابقين تمامًا في التخزين المحلي الأصلي.
- استيراد نسخة عبر `VLexLearningStore.importData`: تحديث المحررين دون تطبيق المسودة المستوردة تلقائيًا.
- سكربت، ومعالجات أحداث، وصورة خارجية، وروابط HTML وSVG، وmeta refresh: لا تنفيذ في الأب ولا طلب خارجي في الاختبار. نص المصدر يبقى في المحرر كما كتبه المستخدم، مع تعطيل روابط التنقل في نسخة المعاينة.
- عرض 390 بكسل دون تجاوز عرض المستند. صورتا `css-lab-mobile.png` و`css-lab-desktop.png` فعليتان من Chromium في الحالة الابتدائية، وصورة `css-lab-security.png` من سيناريو الأمان.

لم تسجل صفحة الاختبار أخطاء JavaScript غير معالجة أو طلبات خارجية. هذا رصد للسيناريوهات المذكورة، وليس ادعاء تدقيق أمني شامل.

## العزل وحماية المسودة

المعاينة تستخدم `iframe sandbox=""` دون أي صلاحيات إضافية. تمنع CSP السكربتات، والاتصال، والموارد الخارجية، وإرسال النماذج. يسمح بتنسيق CSS داخل الإطار وصور data فقط. لا يدخل مصدر المستخدم إلى DOM التطبيق، ولا يستخدم `v-html` أو eval في الأب. تُحلّل نسخة HTML داخل template منفصل وخامل لتعطيل روابط التنقل وmeta refresh قبل إرسالها للإطار؛ هذه الخطوة لا تعدّل النص المحفوظ في المحرر.

حد HTML وCSS هو 100 ألف محرف لكل منهما. عند تجاوز الحد تظهر رسالة ولا يُقص النص ولا تستبدل المعاينة السابقة. لا توجد خدمات مدفوعة أو مكتبات جديدة. صور وخطوط وCSS خارجية لا تُجلب، لذلك تحتاج أمثلتها سياقًا مختلفًا.

## ما لم يُختبر والقيود

- هذه اختبارات المكون مع Vue المحلي والمخزن المشترك الحقيقي، وليست بديلًا عن اختبار تكامله النهائي داخل التطبيق الرئيسي.
- لم تُجر تجربة فعلية على Windows أو Edge أو Safari في هذه المهمة الفرعية. الاختبار في Chromium داخل Linux.
- جرى فحص التجاوب عند 390 و1440 بكسل؛ ليس على كل أحجام الأجهزة أو مع قارئ شاشة.
- توجد حماية تركيب IME في المحررين، لكن لم تُنفذ جلسة كتابة فعلية بلوحة IME في هذا الاختبار.
- المحرر CSS مباشر؛ قواعد CSS الخاطئة قد يتجاهلها المتصفح. لا يوجد محلل CSS مستقل أو وعد بأن كل CSS مكتوب يحقق النتيجة التي يقصدها المستخدم.
- أدوات الحدود الحالية تشمل استدارة الزوايا؛ لا توجد في هذا الإصدار أدوات منفصلة للظلال أو التحولات أو الحركات. يستطيع المستخدم كتابتها في محرر CSS وتطبيقها فعليًا.
- نسب `%` تتبع قواعد CSS الحقيقية؛ ليست تحويلًا ثابتًا إلى بكسل. يمكن تغيير خط `html` في CSS الحر فتتغير rem.
