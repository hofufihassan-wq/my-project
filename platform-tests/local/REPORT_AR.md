# تجهيز التشغيل المحلي والنقل

هذه دفعة التشغيل المحلي فقط. لا تعدّل `main` ولا ترفع كودًا ولا تنشر موقعًا، ولا تغيّر ملفات التطبيق أو التصميم. لم يُحذف أو يُستبدل أي ملف مستخدم أو نسخة احتياطية.

## الملفات

- `start-local.bat`: ملف Windows بترميز ASCII ونهايات CRLF، ينتقل إلى مجلد الملف حتى لو احتوى مسافات، ويجرب `py -3` ثم `python` بعد التأكد من إصدار3.8 أو أحدث. إذا لم يوجد Python تظهر تعليمات تثبيت من مصدره الرسمي؛ لا تنزيل أو تثبيت تلقائي.
- `scripts/start-local.py`: خادم Python قياسي مربوط فقط بـ`127.0.0.1:8091`. يفتح المتصفح بعد بدء الخادم، ويدعم `--no-browser`. Ctrl+C يوقف الخادم فقط ولا يمس بيانات المتصفح.
- `LOCAL_RUN_AR.md`: تعليمات عربية للتشغيل والإيقاف وإعادة الفتح وحفظ الأصل نفسه، مع توضيح أن localhost أو منفذًا آخر لا يقرأ localStorage الخاص بـ127.0.0.1:8091.
- `scripts/package-local.py`: يبني ZIP جديدًا خارج المستودع دون استبدال حزم سابقة، مع جميع ملفات التشغيل وassets ووثائق الجذر وملفات البناء الضرورية والنسختين الأصليتين. يستبعد `.git` و`.env` والمفاتيح والتبعيات والاختبارات والفيديوهات. يسجل commit والفرع وحالة وجود تغييرات غير محفوظة، وبصمات كل ملف داخل `LOCAL_PACKAGE_MANIFEST.json`، وينتج بصمة ZIP جانبية.

## سلوك الخادم

لا فهرسة مجلدات أو كتابة أو upload. يخدم index وJS/CSS التشغيل وassets فقط. لا يكشف `.git` أو `.env` أو التقارير أو السكربتات أو النسخ الاحتياطية عبر HTTP. يرفض المسارات الصاعدة والمخفية والروابط الرمزية التي تخرج من الجذر، ويرفض Host غير محلي. لا يعدّل جدار الحماية ولا ينهي برامج أخرى.

إذا كان خادم **المجلد نفسه** يعمل على8091، يعيد فتحه. إذا شغل المنفذ برنامج مختلف أو نسخة أخرى، يفشل برسالة واضحة دون الانتقال إلى منفذ آخر؛ هذا يحافظ على أصل بيانات المتصفح.

## تحقق فعلي

- `test-local.py`: **5/5** مجموعات، تتضمن عشرات حالات المسارات الفعلية والممنوعة وقراءة ملفات التشغيل وCRLF وحارس إصدار Python.
- `browser.cjs`: **5/5** في Chromium الحقيقي على Linux. صحة endpoint وتكرار التشغيل للمجلد نفسه، تحميل HTML/JS/CSS والخطوط، رفض قراءة الملفات الخاصة وPOST وHost غير محلي، ظهور180 مصطلحًا، نتائج بحث إنجليزية وعربية مطابقة فعلًا، وإضافة المفضلة بزر المصطلح ثم إغلاق المتصفح والخادم بالكامل وفتحهما بنفس profile مع بقاء السجل بالبايت.
- `occupied-port.cjs`: **1/1**، يحتفظ خادم اختباري غير متعلق بالمنفذ8091، ويرفض ملف التشغيل البدء بخروج2 دون إغلاق الخادم أو تغيير المنفذ.
- `package-smoke.cjs`: **2/2** على ZIP الاختبار المستخرج فعلًا إلى مسار يحوي مسافات؛ فُتحت180 مصطلحًا وبحث v-model والمفضلة بعد reload دون أخطاء صفحة.
- بناء ZIP اختُبر فعلًا والتحقق من CRC وبصمة كل ملف، مع وجود25 ملفًا داخل `_pristine_backup` و7 داخل `_v3.5_pre_hands_on_backup`، وعدم وجود `.git` أو dependencies أو أسرار.

أول محاولة متصفح فشلت لأن locator خاطئ اختار181 زرًا بعنوان «إضافة للمفضلة» بدل الزر الحالي؛ أُصلح محدد الاختبار إلى بطاقة المصطلح، دون تغيير التطبيق. المحاولة الثانية الأشد فشلت في فحص Host لأن Node fetch أعاد كتابة الترويسة المرسلة؛ استُخدم `node:http` لإرسال Host الاختبار الحقيقي مع بقاء شرط403 نفسه. سجلات المحاولات الأولى محفوظة وليست نجاحًا. النتائج النهائية في `browser-results.json` والسجلات المجاورة.

## حدود النتيجة

**لم يتوفر Windows أو cmd.exe أو Wine في هذه البيئة.** ملف batch روجع وفُحص نصه فقط؛ التنفيذ الفعلي لخادم Python وChromium والتحقق من الإغلاق وإعادة الفتح كان على Linux. لا ادعاء بأن نقرة ملف BAT جُربت على Windows أو على جهاز المالك.

حزم الاختبار الحالية تحمل `dirty:true` لأنها بُنيت أثناء تطوير المكونات بالتوازي، وليست حزمة الإصدار النهائي. يجب إعادة بناء ZIP بعد اكتمال الدمج المحلي للكود وبناء CSS وحفظ commit النهائي، ثم تشغيل smoke للقاموس على الحزمة المستخرجة نفسها. لا يلزم npm للاستخدام المحلي اليومي.
