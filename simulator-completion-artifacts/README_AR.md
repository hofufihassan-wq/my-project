# أدلة إكمال المحاكي

المرجع الشكلي الحالي عند `c025160` مقبول90% بقرار المستخدم. فرع الإكمال المحلي `feat/simulator-beta-completion` يحافظ عليه ويضيف الوظائف الموضحة في [تقرير التسليم](../SIMULATOR_COMPLETION_REPORT_AR.md).

- `browser/`: قبول متصفح فعلي33/33، يتضمن40 نقرة أصلية،15 تجربة تعليمية، والمقاسات والصور النظيفة.
- `unit/`: وحدة المحيطي13/13؛ نموذج AudioContext للاختبار، وليس ادعاء سماع صوت. قياس الصوت الحقيقي في تقرير المتصفح والفيديو.
- `storage/`: تخزين المتصفح الفعلي3/3: فساد،رفض نسخة الاسترجاع،فشل قراءة عابر.
- `sound/`: صورة أدوات الصوت مفعّلة وبصمات المصدر وحالته الفعلية.
- `demo/`: فيديو22.09ثانية مع الصوت المحيطي وصوت خطأ حقيقي؛التسجيل الخام وخرج الصوت ودليل الالتقاط محفوظة.
- `regression/`:22/22 أمرًا تشمل كل اختبارات ما قبل الإكمال والبناء والتحقق. كل السيناريوهات القديمة باقية.
- `history/`:المحاولات الأولية والتشخيص والفشل،منفصلة عن النجاح النهائي. تقرير الانحدار الأول يحوي18/19 للمحاكي و64/65 للاستقرار قبل انتظار تزامن النقر،ثم رفض اتساق المصدر لأن المصدر تغير أثناء الجولة. لم تُحسب هذه الجولة اعتمادًا نهائيًا.
- `harness-changes.patch`:التعديل الوحيد في الاختبارات السابقة انتظار200ms لتزامن عرض إطار Chromium قبل إرسال النقر الحقيقي؛لا إعادة نقر أو استدعاء DOM.click أو حذف assertions.
- `source-preservation.json`:45/45 ملفًا محميًا وقسما الرئيسية والقاموس مطابقون للأساس.
- `syntax.json`:35/35JS/CJS وفحصPython.
- `delivery-evidence.json`:بصمات المصدر المتطابقة بين الاختبارات والفيديو والصور،وقائمة صور التسليم ومعلومات الفيديو.

جميع الجولات علىChromium154. لاFirefox/WebKit/Safari معتمد بالاختبار. أخطاء `COMPLETION_ACTUAL_ERROR` و`COMPLETION_DEMO_ERROR` مقصودة لإثبات تشخيص الخطأ وصوته، وليست استثناءات تطبيق غير متوقعة. جرد القاموس يقيس جاهزية360 مصدرًا،لا صحتها العلمية،وقد تختلف حالة تحميل مورد خارجي محجوب بحسب توقيت وصول الإشارة.

لم تُرفع تعديلات الكود ولم تُدمج أو تُنشر،ولم تبدأ5C. راجع القيود الدقيقة في التقرير الرئيسي قبل اعتماد النسخة التجريبية.
