# VueLexicon Pro v3.5 — دليل التشغيل والتوثيق الشامل

تطبيق ويب متكامل وتفاعلي يعمل كمعجم برمجي شامل، مسرح لتنفيذ وتتبع الأكواد خطوة بخطوة، معمل لمكونات Nuxt UI v3 و Vue 3، ومختبر تجارب حية للمطورين.

---

## 🚀 1. التشغيل السريع للمالك والمستخدم

المشروع مصمم ليعمل مباشرة وبكل سلاسة دون الحاجة لتثبيت أي برامج أو حزم معقدة:

### الطريقة الأولى (الأبسط — فتح مباشر):
- انقر نقراً مزدوجاً على ملف `index.html` لفتحه في أي متصفح حديث (Google Chrome, Microsoft Edge, Firefox, Safari).

### الطريقة الثانية (خادم محلي خفيف — موصى به لكامل ميزات الـ iframes):
باستخدام سطر الأوامر (PowerShell أو Terminal) داخل مجلد المشروع:

**باستخدام Node.js:**
```bash
npx serve .
# أو
npx http-server -p 8080
```

**باستخدام Python:**
```bash
python -m http.server 8080
```
ثم افتح الرابط في متصفحك: `http://localhost:8080/`

## 🌟 2. استعراض الأقسام والميزات الرئيسية

1. **📖 المعجم الشامل (Lexicon Workspace)**:
   - يضم **180 عنصراً تعليمياً تفاعلياً** عبر 6 تصنيفات:
     - JavaScript (54 مصطلحاً)
     - TypeScript (20 مصطلحاً جديداً)
     - Vue.js 3 (30 مصطلحاً)
     - Nuxt UI (25 مدخلاً)
     - HTML5 (26 عنصراً)
     - CSS3 (25 خاصية)
   - بحث ذكي مع ترتيب الصلة الفوري (Relevance Ranking) والاقتراحات السريعة بأسهم لوحة المفاتيح.
   - شريط «شوهد مؤخراً» لمتابعة تاريخ التصفح.
   - مستويات الإتقان لكل مصطلح: `جديد ⚪`، `أتعلم 🟡`، و `أتقنته 🟢`.
   - إمكانية التبديل بين كود Vue 3 SFC وكود Vanilla JS النقي بنقرة زر واحدة.
   - نسخ آمن وموثوق للكود مع إشعار حالة حقيقي.

2. **⏱️ مسرح تنفيذ الكود (Code Timeline) — الميزة المميزة**:
   - بيئة تتبع تفاعلية للبرامج خطوة بخطوة.
   - تمييز السطر قيد التنفيذ لحظياً.
   - جدول مراقبة المتغيرات (Scope Variables) يوضح القيم وأنواعها ووميض التغيير.
   - سجل Console تتابعي يواكب كل خطوة.
   - أزرار التحكم: خطوة سابقة ⏮️، خطوة تالية ⏭️، تشغيل تلقائي ▶، إيقاف ⏸، وإعادة ↺.
   - شريط مراحل تفاعلي (Scrubber) مع شرح عربي مبسط لكل خطوة.
   - زر مباشر «افتح المفهوم في المعجم» لربط التجربة بالشرح النظري.

3. **🎯 وضع التدريب والاختبارات القصيرة (Practice Quiz)**:
   - أسئلة اختبار تقنية تفاعلية مبنية مباشرة من مفاهيم الموقع.
   - إمكانية تصفية الأسئلة حسب التصنيف (TypeScript, Vue, Nuxt, JS, CSS).
   - عرض بطاقة التفسير التقني والشرح المباشر فور الإجابة لترسيخ الفهم.
   - تقييم محفز وغير عقابي مع إمكانية إعادة المحاولة.

4. **🧪 معمل Nuxt UI Studio**:
   - تجربة وتخصيص مكونات مكتبة Nuxt UI v3 (الألوان، المقاسات، الأنماط، الأيقونات، وحالات التحميل).
   - توليد كود القالب فورياً مع زر النسخ.
   - كتالوج كامل يضم جميع مكونات Nuxt UI مع نوافذ فحص مخصصة.

5. **⚡ مساحة الأكواد الحية (Scratchpad Sandbox)**:
   - محرر أكواد حي مدعوم ببيئة تنفيذ معزولة وآمنة (Sandboxed iframe).
   - قوالب جاهزة (عداد Vue 3، أزرار Tailwind، بطاقات زجاجية، سلة تسوق، وساعة رقمية).
   - نافذة كونسول ملونة تلتقط الأخطاء والسجلات بأمان.
   - زر «إيقاف ⏹» لمقاطعة التنفيذ في حال وجود حلقات طويلة.

6. **📊 حفظ واستعادة البيانات والنسخ الاحتياطي**:
   - حفظ تلقائي للمفضلة، وسجل المشاهدة، ومستويات الإتقان محلياً (Local Storage).
   - تصدير كامل البيانات إلى ملف `JSON` واستيراده بسهولة من نافذة «تعلّمي».

## ⌨️ 3. اختصارات لوحة المفاتيح المدعومة

- `Ctrl + K` (أو `Cmd + K`): التركيز الفوري على شريط البحث.
- `?`: فتح/إغلاق نافذة دليل الاختصارات.
- `Esc`: إغلاق القوائم المنبثقة، النوافذ، وإفراغ نتائج البحث.
- `↑ / ↓` و `Enter`: التنقل والاختيار داخل قائمة اقتراحات البحث.

## 🔄 4. طريقة الرجوع إلى النسخة السابقة (Rollback Guide)

حرصاً على سلامة المشروع وأمان بيانات المالك، تم توفير طريقتين موثوقتين للرجوع للنسخة الأصلية عند الحاجة:

### الطريقة الأولى (النسخة الاحتياطية المباشرة المرفقة):
- يوجد مجلد مستقل باسم `_pristine_backup/` يحتوي على نسخة مطابقة 100% لكافة الملفات الأصلية قبل إجراء أي تعديل.
- للرجوع، يمكنك ببساطة نسخ محتويات مجلد `_pristine_backup/` واستبدال الملفات بها.

### الطريقة الثانية (عبر Git):
تم إنشاء فرع مستقل للتطوير مع حفظ النسخة الأصلية على فرع `master`:
```bash
# للرجوع إلى النسخة الأصلية فوراً:
git checkout master

# للعودة إلى النسخة المطورة:
git checkout feat/vuelexicon-pro-evolution
```
