# أدلة انحدار الدفعة 5B

أُجريت الفحوص في نسخة مستقلة داخل `work/phase5b-regression`، دون استخدام بيانات مستخدم حقيقية أو استبدال تقارير المراحل السابقة. `checks.json` يسجل الأوامر وأكواد خروجها وبصمات ملفات التطبيق المختبرة؛ ملفات JSON داخل مجلد كل اختبار تحفظ تفاصيل الحالات.

- تتوفر Chromium فقط في البيئة. يسجل فحص الاستقرار عدم توفر Firefox وWebKit، ولا يمثل ذلك فحص Safari.
- صور اختبارات الانحدار هنا قد تعرض بيانات fixtures. صور الواجهة المطلوبة للتسليم مأخوذة من سياقات نظيفة منفصلة في `phase5b-artifacts/screenshots`.
- `preservation.json` يقارن 39 ملفًا محميًا بفرع الأساس عند commit `3e9abe7b02f384ed86dd3855cca1ddb633e1e46a`: محتوى القاموس والمنهج، الإرشادات، مخطط البيانات، وحدات المعاينة، التنسيق الأصلي والنسخ الاحتياطية الـ32؛ جميعها مطابقة بايتًا.
- `syntax.json` يحفظ نتيجة 24 فحص صياغة JavaScript/CJS.
- `harness-adaptations.json` يوثق تغييرات الاختبارات: تهيئة القاموس صراحة لأن البداية الجديدة هي الرئيسية، اعتماد لون الخلفية البترولي، ودعم إخراج الأدلة إلى مسار منفصل. لم تُخفف شروط الوظائف أو حماية البيانات.
- احتُفظ بمحاولة فحص كشفت أن utility لون body القديم تتجاوز قاعدة اللون الجديدة داخل `previous-body-specificity-attempt`. أُصلحت specificity في CSS، وأُعيد اختبارا runtime والاستقرار. لا تُعد نتائج المحاولة السابقة نتائج النسخة النهائية.
- فحوص المنهج والمدققات القديمة المصدرية ليست شهادة صحة علمية شاملة للمحتوى. فحص الاستقرار يشغل المراجع التعليمية الـ15 فعلًا داخل الإطار المعزول.

أُعيدت جميع اختبارات المتصفح بعد إضافة safelist تحافظ على فئات Tailwind القديمة المستخدمة داخل المعاينات. يحتفظ `previous-pre-safelist-build` بأدلة البناء السابق، ويثبت تقرير `../runtime-utility-preservation.json` بقاء الفئات القديمة.

كشفت إعادة الاستقرار أيضًا سباقًا قديمًا: callback مغادرة البحث المؤجل كان يغلق الاقتراحات بعد استعادة الحقل للتركيز. حُفظت محاولة 64/65 وإعادة إنتاج حتمية 0/4 قبل الإصلاح في `previous-blur-refocus-attempt`. يُراجع الإصلاح الفعلي عبر الانتظار 300ms بعد مغادرة الحقل وإعادة تركيزه، ثم تأكيد التركيز وإتمام اختيار الاقتراح بلوحة المفاتيح. أُعيدت اختبارات node والاستقرار والصياغة بعد إصلاح guard؛ بقية اختبارات المتصفح كانت ناجحة على CSS النهائي نفسه ووحدات التنفيذ والبيانات نفسها قبل هذا الإصلاح المحدود للبحث.
