## 🚀 1. التشغيل السريع للمالك والمستخدم

المشروع مصمم ليعمل مباشرة وبكل سلاسة دون الحاجة لتثبيت أي برامج أو حزم معقدة:

### الطريقة الأولى (الأبسط — فتح مباشر):
- انقر نقراً مزدوجاً على ملف `index.html` لفتحه في أي متصفح حديث (Google Chrome, Microsoft Edge, Firefox, Safari).

### الطريقة الثانية (خادم محلي خفيف — موصى به لميزات المعاينة المعزولة):
باستخدام سطر الأوامر (PowerShell أو Terminal) داخل مجلد المشروع:

**باستخدام Node.js:**
```bash
npx serve .
# أو
npx http-server -p 8089
```

**باستخدام Python:**
```bash
python -m http.server 8089
```
ثم افتح الرابط في متصفحك: `http://localhost:8089/index.html`

بيئة تعلم برمجي تطبيقي متدرج تنقسم إلى 5 مسارات تعليمية:
- **مسار JavaScript**:
  - `JS-101`: المتغيرات والقيم والقوالب النصية (`let`, `const`, Template Literals وبطاقة الترحيب).
  - `JS-102`: التفريع الشرطي والتحقق من حالة الدخول (`if / else` للتحكم في الواجهة دون أطر خارجية).
  - `JS-103`: مصفوفات البيانات ودالة التحويل `map()` (توليد 3 بطاقات منتجات برمجياً).
- **مسار HTML5**:
  - `HTML-101`: الهيكلية الدلالية السليمة (`article`, `header`, `main`).
  - `HTML-102`: إدراج الوسائط وروابط التنقل الآمنة (`alt`, `target="_blank"`).
  - `HTML-103`: النماذج وحقول الإدخال والتحقق (`form`, `type="email"`).
- **مسار CSS3**:
  - `CSS-101`: التخطيط المرن الحديث `Flexbox`.
  - `CSS-102`: التخطيط الشبكي ثنائي الأبعاد `CSS Grid`.

- **مسار TypeScript**:
  - `TS-101`: كتابة الأنواع البدائية وتأكيد المعاملات والدوال.
  - `TS-102`: توثيق وتأمين الكائنات عبر الواجهات البرمجية `Interfaces`.
  - `TS-103`: أنواع الاتحاد وتضييق الأنواع في وقت التشغيل `Union & Narrowing`.
- **مسار Vue 3**:
  - `VUE-101`: التفاعلية وعرض البيانات مع `ref()` وربط الأحداث `@click`.
  - `VUE-102`: التوجيهات الهيكلية لعرض البيانات والقوائم (`v-if`, `v-for`, `:key`).
  - `VUE-103`: بناء وتمرير الخصائص للمكونات المستقلة `Components & Props`.

### 3. 🖥️ بيئة العمل المزدوجة المتطورة (Dual-Pane Workspace)
- **الجانب الأيسر (Left - LTR)**:
  - محرر كود سريع مع أرقام الأسطر وإمكانية استخدام مفتاح Tab لاختيار مقترحات الإكمال التلقائي.

  - سجل الكونسول المدمج الملون.
- **الجانب الأيمن (Right - Arabic RTL)**:
  - بطاقة أهداف الدرس والمهام المرقمة.
  - قائمة معايير النجاح القابلة للفحص التلقائي.
  - التلميحات التدريجية وخيار عرض الحل النموذجي المرجعي مع التوثيق النزيه.
  - زر فحص الحل وتأكيد الإنجاز، وأزرار التنقل التسلسلي التلقائي لفك قفل الدروس التالية.
  - رابط التوثيق الرسمي لكل تقنية (MDN, JavaScript.info, TypeScript Handbook, Vuejs.org).
  - نافذة «محاكاة تتبّع الكود التعليمية» لفهم حركة المتغيرات والذاكرة خطوة بخطوة في الدروس المدعومة.

## 🔒 4. الأمان والممارسات الهندسية

- **عزل إطار كود المستخدم**: يعمل في بيئة رملية معزولة بدون صلاحية `allow-same-origin` لمنع الوصول لـ localStorage أو سياق التطبيق الرئيسي.
- **صفر مفاتيح API أو أسرار**: التطبيق محلي بالكامل ولا يحوي أي مفاتيح سرية في ملفات الواجهة الأمامية.
- **التخزين الآمن SafeStorage**: معالجة حالات التصفح الخفي وأخطاء نفاد الحصة التخزينية بسلاسة.
- **النسخ الاحتياطي الأصلي**: تتوفر نسخة احتياطية أولية كاملة وغير ملموسة في مجلد `_pristine_backup/`.
