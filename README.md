التشغيل الموصى به من جذر المستودع: `python3 -m http.server 8091 --bind 127.0.0.1` (على Windows: `py -3 -m http.server 8091 --bind 127.0.0.1`). تحتاج جميع ملفات JavaScript وCSS ومجلد `assets`. فتح `file://` ليس مسار التشغيل المعتمد. لا يحتاج تشغيل النسخة الجاهزة npm.

المشاريع وKanban والملاحظات والتقويم وشرح الأكواد العام صفحات تأسيسية، وليست أدوات إدارة مكتملة. الثيمات الثلاثة متاحة للجلسة، وحفظها الدائم غير منفذ. قيود مختبر CSS ونتائج تدقيق المحتوى والحفظ والمحاكي في [تقرير التدقيق المستقل](VUELEXICON_INDEPENDENT_AUDIT_AR.md) وأدلته داخل `audit-artifacts/`.

**كل ما يلي سجل تاريخي للمراحل السابقة، وقد يصف واجهات أو تعليمات لم تعد مطبقة. لا تعتمد تعليمات الدرجات والأقفال وCDN وفتح الملف مباشرة أدناه بوصفها حالة النسخة الحالية.**

# VueLexicon Pro 4.0 — المرحلة الرابعة: الاستقرار

الفرع `fix/phase4-stability-review` من main بعد دمج المرحلة الثالثة عبر PR #3. أُصلحت المفضلة، وقراءة المسودات، وترتيب الاستيرادات، والبحث والاختصارات، وقص أزرار الترويسة على الجوال والتابلت. بقي المحتوى والتصميم الحالي والنسخ الاحتياطية، ومكتبات Vue/CSS المحلية وعزل المعاينة.

شغّل `python3 -m http.server 8091` من جذر المستودع وافتح `http://localhost:8091/`. أبق مجلد `assets` وجميع ملفات JavaScript، ومنها `legacy-validator-guards.js`. لا تحتاج npm لتشغيل النسخة الجاهزة، ولا تمسح localStorage للتجربة. استخدم منفذًا مستقلًا عن الأصل إذا أردت فصل البيانات.

اقرأ [تقرير الاستقرار](PHASE4_STABILITY_REPORT_AR.md) للأعطال وإعادة إنتاجها والملفات والاختبارات، و[ملف المتابعة](PROJECT_STATUS_AR.md). نجحت 40/40 أوامر نهائية، و 65/65 لفحوص الاستقرار على Chromium. Firefox/WebKit غير مثبتين، ولم يُعتبرا ناجحين. الحماية المضافة لـ JS-101 و TS-101 محدودة؛ 0B ليس مكتملًا ولم تعد درجات أو اختبارات إجبارية.

Vue3.4.21 ومترجم SFC و CSS والخطوط محلية. TypeScript و Nuxt والمكتبات والملفات الإضافية خارج نطاق المشغل المستقل؛بعض الأمثلة الأصلية ناقصة، ولم تُعدّل. جرد 360 مصدرًا لا يعني أن 360 مثالًا مكتمل أو اختُبرت كل أحداثه. الصور والوسائط و fetch الاختيارية تحتاج شبكة.

لإعادة البناء: `npm ci --ignore-scripts` ثم `npm run build:compiler` و`npm run build:css`. للتحقق: `npm run verify:assets`. لا Vite أو خدمات جديدة. تقارير [المرحلة الثالثة](SFC_PREVIEW_REPORT_AR.md) و[الملفات المحلية](RUNTIME_ASSETS_REPORT_AR.md) محفوظة كتاريخ.

هذه نسخة للمراجعة فقط؛ **لا دمج في main ولا مرحلة خامسة أو نشر موقع**. الدليل أدناه تاريخي.

## 🚀 1. التشغيل السريع للمالك والمستخدم

المشروع مصمم ليعمل مباشرة وبكل سلاسة دون الحاجة لتثبيت أي برامج أو حزم معقدة:

### الطريقة الأولى (الأبسط — فتح مباشر):

**باستخدام Node.js:**
```bash
npx serve .
# أو
npx http-server -p 8089
```

**باستخدام Python:**
```bash
python -m http.server 8089
```
ثم افتح الرابط في متصفحك: `http://localhost:8089/index.html`

### 2. 💻 وضع التدريب العملي الحي (Hands-on Practice Tracks)
بيئة تعلم برمجي تطبيقي متدرج تنقسم إلى 5 مسارات تعليمية:
- **مسار JavaScript**:
  - `JS-101`: المتغيرات والقيم والقوالب النصية (`let`, `const`, Template Literals وبطاقة الترحيب).
  - `JS-102`: التفريع الشرطي والتحقق من حالة الدخول (`if / else` للتحكم في الواجهة دون أطر خارجية).
  - `JS-103`: مصفوفات البيانات ودالة التحويل `map()` (توليد 3 بطاقات منتجات برمجياً).
- **مسار HTML5**:
  - `HTML-101`: الهيكلية الدلالية السليمة (`article`, `header`, `main`).
  - `HTML-102`: إدراج الوسائط وروابط التنقل الآمنة (`alt`, `target="_blank"`).
  - `HTML-103`: النماذج وحقول الإدخال والتحقق (`form`, `type="email"`).
- **مسار CSS3**:
  - `CSS-101`: التخطيط المرن الحديث `Flexbox`.
  - `CSS-102`: التخطيط الشبكي ثنائي الأبعاد `CSS Grid`.
  - `CSS-103`: التصميم المتجاوب واستعلامات الوسائط ومتغيرات CSS.
- **مسار TypeScript**:
  - `TS-101`: كتابة الأنواع البدائية وتأكيد المعاملات والدوال.
  - `TS-102`: توثيق وتأمين الكائنات عبر الواجهات البرمجية `Interfaces`.
  - `TS-103`: أنواع الاتحاد وتضييق الأنواع في وقت التشغيل `Union & Narrowing`.
- **مسار Vue 3**:
  - `VUE-101`: التفاعلية وعرض البيانات مع `ref()` وربط الأحداث `@click`.
  - `VUE-102`: التوجيهات الهيكلية لعرض البيانات والقوائم (`v-if`, `v-for`, `:key`).
  - `VUE-103`: بناء وتمرير الخصائص للمكونات المستقلة `Components & Props`.

### 3. 🖥️ بيئة العمل المزدوجة المتطورة (Dual-Pane Workspace)
- **الجانب الأيسر (Left - LTR)**:
  - محرر كود سريع مع أرقام الأسطر وإمكانية استخدام مفتاح Tab لاختيار مقترحات الإكمال التلقائي.
  - إطار معاينة معزول حقيقي (`sandbox="allow-scripts"`) مع شارات الحالة الخمس (`جاهز`، `جارٍ التشغيل`، `المعاينة جاهزة (قد يستمر الكود)`، `يوجد خطأ`، `متوقف`).
  - زر «إيقاف / إعادة ضبط ⏹» لاستبدال الإطار وإبطال جلسة التشغيل. اختُبر بمؤقت فعلي؛ لا يضمن مقاطعة الحلقات اللانهائية التي تحجب المتصفح.
  - سجل الكونسول المدمج الملون.
- **الجانب الأيمن (Right - Arabic RTL)**:
  - بطاقة أهداف الدرس والمهام المرقمة.
  - قائمة معايير النجاح القابلة للفحص التلقائي.
  - التلميحات التدريجية وخيار عرض الحل النموذجي المرجعي مع التوثيق النزيه.
  - زر فحص الحل وتأكيد الإنجاز، وأزرار التنقل التسلسلي التلقائي لفك قفل الدروس التالية.
  - رابط التوثيق الرسمي لكل تقنية (MDN, JavaScript.info, TypeScript Handbook, Vuejs.org).
  - نافذة «محاكاة تتبّع الكود التعليمية» لفهم حركة المتغيرات والذاكرة خطوة بخطوة في الدروس المدعومة.

## 🔒 4. الأمان والممارسات الهندسية

- **عزل إطار كود المستخدم**: يعمل في بيئة رملية معزولة بدون صلاحية `allow-same-origin` لمنع الوصول لـ localStorage أو سياق التطبيق الرئيسي.
- **صفر مفاتيح API أو أسرار**: التطبيق محلي بالكامل ولا يحوي أي مفاتيح سرية في ملفات الواجهة الأمامية.
- **التخزين الآمن SafeStorage**: معالجة حالات التصفح الخفي وأخطاء نفاد الحصة التخزينية بسلاسة.
- **النسخ الاحتياطي الأصلي**: تتوفر نسخة احتياطية أولية كاملة وغير ملموسة في مجلد `_pristine_backup/`.
