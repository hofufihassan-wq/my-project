## التشغيل

1. فك حزمة Windows كاملة في مجلد عادي.
2. ثبّت Python3.8 أو أحدث مجانًا عند الحاجة، مع Add Python to PATH.
3. افتح `start-local.bat` واترك نافذته مفتوحة؛ العنوان `http://127.0.0.1:8091/`.
4. للإيقاف Ctrl+C، ثم أعد فتح الملف نفسه للعودة. استخدم المتصفح والملف الشخصي والعنوان أنفسها لتظهر بياناتك.

لا يلزم npm أو GitHub أو اشتراك أو تغيير جدار الحماية. راجع `LOCAL_RUN_AR.md` داخل الحزمة للأعطال والنسخ الاحتياطي. بيانات القاموس القديمة والتعلّم الجديدة لها ملفا تصدير مستقلان.
