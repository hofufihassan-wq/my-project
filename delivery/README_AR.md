هذه الحزمة مبنية من commit b7a20fd8aa64023da6796d80e9abb4c0ffc925dc بحالة Git نظيفة. ملفات التطبيق لم تتغير عن النسخة التي اجتازت الاختبارات النهائية. تقرير التشغيل من ZIP نفسه في VERIFICATION.json، وبصمة الملف في SHA256SUMS.txt. رقم commit الذي يضيف هذه الحزمة إلى فرع التسليم يختلف عن commit البناء، لأن إضافة الحزمة والأدلة لاحقة للبناء.
