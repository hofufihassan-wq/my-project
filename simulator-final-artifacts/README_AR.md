# أدلة التصميم الزجاجي النهائي

المرجع هو الصورة الأحدث التي أرسلها المستخدم بعد إلغاء اختياره السابق، وليس03_simulator_blue_tech.jpg. راجع `reference/REFERENCE_DECISION_AR.md` و[تقرير التسليم](../SIMULATOR_FINAL_GLASS_REPORT_AR.md).

- `browser/`: قبول43/43 يتضمن السحب واللمس والمقاسات والمخطط والإحصاءات والدروس15 وحفظ مسوداتها وإعادة تحميلها.
- `regression/`:25/25 أمرًا؛ كل الاختبارات السابقة والبناء والأصول. نجح24 أمرًا في الجولة الكاملة الأخيرة، وأعيد الفحص المتأثر كاملًا33/33 بعد تصحيح القياس الذري للحدود في الاختبار، دون تغيير ملفات التشغيل. لا حذف لحالات حماية أو بيانات أو أمثلة غير مدعومة.
- `screenshots/`:21 صورة متصفح فعلية عند1440/768/390 ولقطات مركزة وحالة فارغة وخطأ حقيقي. دفتر التصوير يثبت8 محاولات مراجعة حقيقية:6 جاهزية و2 أخطاء مقصودة، وليست بيانات صاحب المشروع.
- `demo/`: تسجيل متصفح فعلي مع السحب والتحكم بالمقاس والتشغيل والمعاينة وConsole والإيقاف وإعادة التعيين؛ الصوت هو خرج القناتين المعتمدتين منWebAudio، لا مسارًا بديلًا.
- `source-preservation.json`:47/47 ملفًا محميًا، مع تطابق الرئيسية والقاموس نصيًا. ملف الصوت المعتمد نفسه محفوظ بالبايت.
- `syntax.json`:38/38JS/CJS وفحصPython. الأصول المحلية27/27.
- `harness-changes.patch`: اختيار لوحة«الكل»/«المعاينة» الحقيقي في الاختبارات القديمة، وتمريرiframe والزر للشاشة قبل النقر الأصلي، وانتظار الحالة الفعلية للانتقال، وفحص نبضة حدث فعلية بدل زخرفة مستمرة. تحولت نقرةDOM القديمة في فحص الأصول إلى نقرة مؤشر أصلية.
- `history/`: الفشل والمحاولات الأولية والتشخيص، بما فيه اختلاف تقريب حجم اللوحة، وتأخر انتقال الإخفاء، والإطار خارج الشاشة، وفرق22/23px في ترقيم الكود، وقياس المعاينة وهي مخفية قبل إصلاحه، وجولتي24/25 قبل تصحيح قياس الحدود أثناء التمرير الناعم، وفحص الأحجام الدنيا قبل تصحيح تداخل اللوحات. النتائج التاريخية ليست اعتماد النسخة النهائية. أبقينا سجلات وتقارير المحاولات ولا نكرر كل صور الجولات السابقة.
- `delivery-evidence.json`: تطابق بصمات المصدر بين القبول والانحدار والتصوير والفيديو، وبيانات ملفات التسليم.
- [review.html](review.html): معرض محلي للصور والفيديو والمقارنة، دون خدمة نشر أو موارد خارجية.

Chromium هو المتصفح المختبر. Firefox/WebKit غير متوفرين، ولا ادعاء باختبارSafari أو أجهزة هاتف فعلية أو صحة منطق كل برنامج. جرد360 مصدرًا لا يعني أن360 برنامجًا مكتملًا تعمل؛ بقيت المصادر الناقصة وأخطاؤها الأصلية.

كل الأوقات في سجل الإشارات أوقات استلام، لا مدد تنفيذ. النسب من الأعداد الفعلية وبالتعريف الظاهر، لا درجات تعليمية أو إثبات صحة عامة. لم يُرفع الكود أو يُدمج أو يُنشر، ولم تبدأ5C.
