# دليل تشغيل VueLexicon Pro محلياً على Windows

مرحباً بك في النسخة المحلية المستقلة لقاموس ومحاكي **VueLexicon Pro** على بيئة نظام Windows.

---

## 🚀 طريقة التشغيل السريع (بنقرة واحدة)

1. انقر نقراً مزدوجاً على الملف:
   ```cmd
   start-local.bat
   ```
2. سيقوم السكريبت تلقائياً بالتحقق من بيئة التشغيل، تشغيل خادم محلي خفيف على المنفذ `5173`، وفتح متصفحك الافتراضي مباشرة على العنوان:
   ```text
   http://127.0.0.1:5173/
   ```
3. لإيقاف الخادم عند الانتهاء، أغلق نافذة الأوامر أو اضغط `Ctrl + C`.

---

## 📋 متطلبات التشغيل

* **الخيار الأساسي (الموصى به):** [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
  * يوفر أفضل أداء لمعاينة أكواد Vue SFC وتشغيل Web Workers محلياً.
* **الخيار البديل:** [Python](https://www.python.org/) (الإصدار 3.8 أو أحدث).
  * يقوم سكريبت `start-local.bat` بالتبديل تلقائياً إلى خادم Python في حال عدم توفر Node.js.

> **لماذا نحتاج خادماً محلياً بدلاً من فتح `index.html` مباشرة؟**  
> المتصفحات الحديثة تمنع بروتوكول `file:///` من تشغيل Web Workers وعزل إطارات Iframe التفاعلية ومحلل SFC لأسباب أمنية (CORS / Same-Origin Policy). الخادم المحلي يضمن عمل كافة ميزات القاموس والمحاكي والشرح بدون أي قيود.

---

## 🔍 الميزات المفحوصة والمتاحة في هذه النسخة

1. **القاموس الكامل (180 مصطلحاً):**
   * يغطي 6 مسارات تقنية: HTML5، CSS3، JavaScript، Vue 3، Nuxt UI، TypeScript.
   * لكل مصطلح: الشرح النظري، مثال Vue SFC، مثال Vanilla JS، جدول الخصائص، الملاحظات والمحاذير، والرابط الرسمي للمرجع (MDN / Vue Docs).
2. **البحث المتقدم والفهرس الأبجدي:**
   * تصفية فورية حسب الفئات، البحث السريع بالنص العربي والإنجليزي، واقتراحات الإكمال التلقائي.
3. **المفضلة وحفظ التقدم (Persistence):**
   * حفظ محلي آمن في متصفحك عبر `localStorage` مع عزل كامل، حماية المسودات من الضياع، وإمكانية التصدير والاستيراد الذري بصيغة JSON.
4. **المحاكي المتقدم (Simulator Workbench):**
   * معاينة معزولة للأكواد في إطار Sandbox آمن.
   * صوت محيطي اختياري (أمواج متباعدة هادئة خالية من الزنّة) ومؤشرات حالة تشغيل بصرية.
5. **محلل الأكواد سطرًا بسطر (Code Explainer):**
   * تحليل هيكلي محلي عبر Web Worker دون إرسال أي كود خارج جهازك.

## ⚠️ حدود التحقق للأمثلة الـ 360 (Verification Boundaries)

تم فحص ومراجعة كافة الأمثلة الـ 360 كودياً واختبارها عبر بيئة Chromium الحقيقية:
* **الأمثلة المستقلة القابلة للتنفيذ:** تعمل مباشرة وتظهر النتائج التفاعلية داخل إطار المعاينة.
* **المقتطفات النحوية التوضيحية (Syntax Snippets):**
  * بعض أمثلة Vanilla JS مصممة لتوضيح دالة معينة (مثل `addEventListener` أو `classList.add`) وتفترض مسبقاً وجود عنصر في الصفحة (`#btn`)؛ عند تشغيلها في إطار فارغ تظهر رسالة تشخيصية توضح ذلك بأمان.
  * أمثلة **Nuxt UI** (مثل `<UButton>` و `<UCard>`): توضح صياغة مكتبة Nuxt UI الرسمية، وتتطلب بيئة مشروع Nuxt كاملة، ويظهر المحاكي رسالة تشخيصية عربية تفيد بأن المكون يحتاج مكتبة Nuxt.
  * أمثلة **TypeScript**: تقدم صياغة TypeScript القياسية، ويقتصر مشغل المعاينة على فحص البنية اللغوية دون تحويل TS إلى JS أثناء التشغيل المباشر.
