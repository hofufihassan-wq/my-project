## ما جُرّب فعلًا

- `check-package.py`: ستة فحوص ناجحة؛ تطابق ZIP والمجلد والبصمات، حدود الملفات العامة، مراجع HTML وCSS وبيان المكتبات، رفض سكربت مفقود وCSS فارغ ومكتبة معدلة، ورفض إخراج الحزمة داخل checkout. لا يحذف المُصدّر أي ملفات ولا يستبدل حزمة قديمة.
- `python3 scripts/assets.py verify`: تطابقت 27 بصمة أصول وتراخيص محلية مع قفل المشروع الحالي. لم يُعاد بناء CSS لأن ملفات تشغيل الواجهة لم تتغير.
- `browser-static.cjs`: Chromium حقيقي على Linux عند `/` و`/review/` عبر HTTP محلي، مع حظر الطلبات الخارجية. في كل مسار اشتغل Vue، فُتح القاموس من زر ظاهر، وظهر 8 نتائج لبحث `ref` و18 نتيجة لبحث `مصفوف`، وجُلِبت الأصول الثمانية والثلاثون المرتبطة مباشرة في HTML بحالة 200. لم تسجل أخطاء JavaScript أو طلبات خارجية.
- الصورتان `static-root.png` و`static-nested.png` التقطهما المتصفح الفعلي، دون تعديل أو توليد تخيلي. النتائج الآلية القابلة للمراجعة في `package-results.json` و`browser-results.json`.
- شُغّل `scripts/start-local.py --no-browser` فعليًا مرة واحدة على `127.0.0.1:8091`؛ استجاب مسار الصحة، ورُفض طلب `.git/config` و`.env` وREADME والنسخ الأصلية وسكربت الخادم بحالة 404. أُوقف process الاختبار وحده بـSIGINT.

المحاولة الأولى لفحص المتصفح توقفت لأن محدد الاختبار طابق زري التنقل للكمبيوتر والجوال المخفي معًا. حُفظ سجلها في `browser-attempt-1.json`، ثم حُدد الزر الظاهر في الاختبار. لم يُغيّر كود التطبيق لإرضاء الفحص.

## ما لا تثبته هذه الفحوص

لا تثبت هذه المهمة اكتمال كل الصفحات أو أمثلة القاموس، ولا صحة كل درس أو المشغّل. مشكلة ابتلاع عناصر الرئيسية داخل وسم `vlex-dashboard` ذاتي الإغلاق مكتشفة في الفحص الرئيسي، وتنتظر قرار المستخدم؛ حزمة المصدر المذكور لا تصلحها. لم تُضف ميزات أو ذكاء اصطناعي، ولم تُعدّل التصميم.

راجعت `start-local.bat` و`LOCAL_RUN_AR.md` قراءةً فقط: المسارات مقتبسة، وفحص Python يشترط 3.8 أو أحدث ويدعم `py -3` ثم `python`. لا تتوفر Windows أو CMD/Wine هنا؛ **لم يُنفذ BAT على Windows فعليًا**. الاختبار المذكور للخادم هو Python/Chromium على Linux. راجع التقرير الرئيسي لفحوص الحفظ والمفضلة والدروس والمختبرات الأوسع.

لم يُختبر HTTPS أو Cloudflare أو ربط GitHub أو حدود الخطط الحالية، ولم تُجرَ محاولة اتصال خارجية في هذه المهمة. يجب إعادة اختبارات العنوان النهائي عند السماح بالنشر. تبقى بيانات المستخدم في localStorage لكل origin؛ راجع `FREE_HOSTING_AR.md` لتصدير نسختي بيانات القاموس والتعلّم قبل نقل العنوان.
