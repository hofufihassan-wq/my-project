# إصلاح الروابط الداخلية في معاينة srcdoc

تاريخ الفحص: 2026-11-07. الملف التنفيذي المعدل الوحيد في هذا الإصلاح: `preview-runner.js`، داخل `childBootstrap` الذي ينفذ **في iframe فقط**. لم يُعدّل CSS أو sandbox أو التخزين أو بروتوكول الرسائل.

## العيب المثبت

عند تشغيل HTML يحتوي `href="#goal"` في iframe ذي `srcdoc`، يرث المستند `baseURI` من صفحة التطبيق. كان النقر بالماوس أو Enter ينتقل بالإطار إلى عنوان صفحة التطبيق مع `#goal`، فيختفي المثال ويُحمّل التطبيق داخل الإطار المعزول. حالة `PREVIEW_READY` السابقة لا تثبت بقاء المثال بعد هذا التنقل.

أُعيد إثباته في مشغّل الدروس الفعلي بواسطة وكيل الدروس، وفي فحص مستقل يمر عبر `VueLexiconRunner.buildDocument`، ثم في محرر المحاكي الفعلي. لا تكفي جاهزية الإطار معيارًا هنا؛ القياسات تشمل عنوان المستند، نص الهدف الأصلي، مقدار التمرير وموضع الهدف.

## التصحيح وحدوده

مستمع `click` في الطفل يعالج فقط الروابط التي تبدأ بـ`#` وتستهدف المستند نفسه، دون مفاتيح تعديل أو خاصية تنزيل. يمنع تنقل `srcdoc` إلى عنوان التطبيق ويبحث عن `id` أو رابط `name` داخل المثال ثم يمرر إليه. يدعم فك ترميز المعرّفات، والجزء الفارغ للعودة إلى الأعلى، و`#top` عند عدم وجود هدف بهذا الاسم. لا يخرج المستند عند غياب الهدف أو الترميز غير الصحيح.

- يحترم `preventDefault()` الذي استُدعي قبل وصول الحدث إلى هذا المستمع، مثل معالج العنصر أو الوثيقة. لا يَعِد بمحاكاة ترتيب كل معالج نافذة يُسجَّل بعده.
- الروابط إلى مستند آخر وروابط الهدف الآخر والتنزيل والنقر مع مفاتيح تعديل تحتفظ بمعالجتها السابقة؛ ليست هذه إضافة لدعمها أو إلغاء قيود sandbox عليها.
- التصحيح تمرير داخل المثال، وليس محاكاة `History API` أو `location.hash` أو `hashchange`. لا يغير الجزء الظاهر في عنوان iframe ولا يمنع كود المستخدم من محاولة التنقل برمجيًا.
- لا يضيف `allow-same-origin` أو `allow-top-navigation`، ولا يشغل كود المستخدم في الصفحة الأم. لا يمثل هذا المستمع حدًا أمنيًا بديلًا عن sandbox.

الفشل الثماني قبل الإصلاح شمل الماوس، Enter، معرّفًا عربيًا مرمزًا، الجزء الفارغ، هدفًا غير موجود، ترميزًا غير صحيح، رابط `name` قديمًا، والتشغيل من محرر المحاكي الحقيقي. نجحت الحالات الثماني نفسها بعد الإصلاح، كما استمر نجاح معالج المستخدم الذي يلغي التنقل، والرابط إلى مستند آخر، وعزل الأب، ورفض الرسائل ذات المصدر أو الجلسة أو الحمولة الخاطئة.

`#top` معالج في الكود لكنه **لم يكن حالة مستقلة في جولة المتصفح هذه**. كذلك لم يُختبر كل تفاعل بين مفاتيح التعديل و`target` و`base[target]` في كل متصفح؛ لا يُعمّم نجاح الحالات الاثنتي عشرة على ذلك.

## إعادة التشغيل

```sh
node resume-checks/fragments/browser.cjs rerun-<اسم-جديد>
node run_preview_protocol_tests.js
node run_data_safety_tests.js
```

تحتاج جولة المتصفح Chromium وPlaywright وFFmpeg المتوفرة في بيئة التدقيق. يكتب الاختبار صورًا وفيديو وJSON في المجلد المسمى؛ استخدم اسمًا جديدًا للحفاظ على الأدلة السابقة. الخادم مؤقت ومربوط بـ`127.0.0.1` ويُغلق مع متصفح الاختبار. لا يستخدم GitHub أو خدمة خارجية أو بيانات المستخدم الحقيقية.

هذا الإصلاح لا يعلن جاهزية جميع صفحات المشروع؛ عيب ربط صفحات التنظيم وعيب وسم الرئيسية وتقارير الدروس لها أدلة وتسليم منفصل.
