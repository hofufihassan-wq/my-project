# S4 — إعادة جميع اختبارات الانحدار السابقة

نتيجة النسخة النهائية: **19/19 أمرًا ناجحًا**: بناء المترجم، بناء CSS، التحقق من 27 أصلًا، وجميع ملفات الاختبار/الجرد السابقة الستة عشر. `checks.json` يسجل الأوامر وأكواد الخروج وبصمات المصدر المختبر؛ لم تُحسب محاولة جزئية نجاحًا.

- `syntax.json`: ‏27/27 فحص صياغة JS/CJS.
- `source-preservation.json`: ‏39/39 ملفًا محميًا مطابقًا للأساس قبل النسخة التجريبية، بما فيها المحتوى والمعرفات والمنهج ومخطط البيانات ووحدات المعاينة والتنسيق الأصلي والنسخ الاحتياطية الـ32.
- `harness-adaptations.json`: كل تعديل على الاختبارات الأصلية وسببه والـdiff؛ أُضيفت dependency الحقيقية `simulator-beta.js` إلى fixtures الـVM، واستُبدلت محددات واجهة سابقة بعناصر beta الحقيقية، مع الانتقال والاختيار والتحجيم والنقر الفعلي. بقيت شروط المصدر والمسودات والتخزين والاستيراد والعزل والرسائل والتفاعل فعالة.
- في مراجعة المحاكي، بقيت بصمات وحدات التنفيذ والصفحة الرئيسية محمية مقابل أساسها الأصلي. تغيرت مقارنة نص دالتي التطبيق الأم فقط إلى commit ‏S2 المراجع `3f4dfdd`، لأن تسجيل استقبال الأحداث إضافة معتمدة. شُدّد اختبار الرسائل المزورة ليحمي أيضًا سجل الأحداث والخطأ المعروض.
- `initial-pre-adaptation-attempt` يحتفظ بفشل المحددات ونص الدوال قبل تحديث الاختبارات، وسجلات المهلات الجزئية ودليل المتصفح على المحددات القديمة. هذه نتائج محاولة تاريخية ولا تمثل النسخة النهائية.
- `run_phase5b_browser_tests` و`run_phase5b1_browser_tests` أُجريا بصورة مستقلة بواسطة `/root/inspect_tests` على المصدر النهائي نفسه، وجرى التحقق من بصماتهما؛ النتائج ‏32/32 و34/34. بقيت الصفحة الرئيسية مطابقة بكسليًا عند 1440 و768 و390. مدة تشغيلهما غير مسجلة، ولذلك لا ننسب لهما مدة مختلقة.
- الجرد النهائي ‏360/360 بلا مهلات أو خرق مصدر/تخزين: Vue ‏96 جاهزًا أوليًا و84 خطأ؛ Vanilla ‏121 و59. هذه حالات جاهزية أولية، وليست شهادة دقة تعليمية أو اكتمال كل التفاعلات. تباين أولي بسبب مورد صورة خارجي موثق في `inventory-readiness-variation.json`.
- جميع فحوص المتصفح على Chromium. يسجل فحص الاستقرار عدم توفر Firefox وWebKit؛ لا ادعاء باختبارهما أو Safari.
- صور الانحدار قد تعرض بيانات fixtures معزولة. لا تمثل بيانات مستخدم حقيقية أو صور التسليم النظيفة الخاصة بـS4.

لم تُعدّل ملفات تشغيل التطبيق أو تصميمه أثناء عمل الانحدار. حُفظت الأدلة الجديدة في مجلد S4 فقط؛ بقيت تقارير المراحل السابقة كما كانت.
