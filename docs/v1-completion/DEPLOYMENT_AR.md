# تجهيز الاستضافة الثابتة — دون نشر

> تقرير تحضير المرحلة E محفوظ. تعليمات النشر الأحدث والمراجعة المطلوبة في [docs/deployment](../deployment/README_AR.md).

الفرع المرشح: `feat/vlex-v1-followup`. لم يُدمج في main، ولم يُنشأ موقع أو حساب استضافة. هذه تعليمات المرحلة التالية بعد مراجعة المستخدم، وليست سجل نشر.

## البناء

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
```

يتطلب البناء Node.js 22 أو أحدث وPython 3. تُبنى CSS محليًا، وتُراجع بصمات الأصول المثبتة وتراخيصها، ثم يُنتج مجلد `dist/`. أمر البناء لا ينفذ نشرًا ولا يستخدم خدمات مدفوعة. لا يحتاج التطبيق خادم API أو متغيرات بيئة أو مفاتيح خدمات في وقت التشغيل.

يحتوي `dist/release-manifest.json` على إصدار المنتج وبصمة SHA-256 وحجم كل ملف موزع. الإصدار 1.0.0 في package.json يصف المنتج؛ لا يغير إصدار مخطط بيانات المستخدم أو صيغ النسخ القديمة.

الموزع قائمة مسموحة لملفات التشغيل فقط. لا يتضمن Git أو node_modules أو الاختبارات أو تقارير المستودع أو نسخ المستخدمين. يرفض البناء مجلد إخراج يحوي ملفات قديمة غير معروفة، بدل نشرها أو حذفها تلقائيًا. عند التعارض اختر مجلدًا جديدًا باستخدام `python3 scripts/prepare-v1-static.py --output /tmp/vlex-public-build` بعد بناء CSS والتحقق من الأصول.

## إعداد Cloudflare Pages لاحقًا

بعد الموافقة على النشر: اربط المستودع الخاص بتفويض محدود، واختر الفرع المعتمد، واجعل أمر البناء `npm run build` ومجلد الإخراج `dist`. لا تجعل جذر المستودع مجلد النشر، ولا تحول المستودع إلى Public. ثبّت إصدار Node المتوافق، وتحقق من توفر Python 3 في بيئة البناء. لم يُنفذ أي من ذلك في هذه الجولة.

ملف `_headers` الموزع يضبط `no-cache` وإعادة التحقق من الملفات لتجنب بقاء JavaScript قديم بعد التحديث، مع `nosniff` وسياسة مرجع محدودة. لم تُضف سياسة عامة تمنع المحررات أو Workers أو المعاينات القائمة. التطبيق يستخدم موارد تشغيل محلية، وروابط المراجع الخارجية اختيارية.

## بيانات المستخدم قبل الانتقال إلى رابط جديد

التقدم والمسودات والإعدادات محلية لكل متصفح ولكل origin. **الانتقال من localhost أو نطاق سابق إلى نطاق Cloudflare لا ينقل localStorage تلقائيًا.** يجب تصدير النسخة الشاملة من الإعدادات في الموقع القديم، ثم استيرادها في الموقع الجديد والتحقق من التقدم قبل الاستغناء عن النسخة القديمة. لا تُرفع نسخ المستخدمين إلى GitHub.

الحفظ الحالي ليس مزامنة حسابات أو نسخًا سحابيًا آليًا. توجد نسخة تصدير كاملة واستيراد متحقق منه واسترجاع محلي، وتبقى النسخة الخارجية الدورية مسؤولية المستخدم. تحديث ملفات الموقع لا يستدعي مسح بيانات المتصفح. القيود الحالية: مخزن التعلم حتى 2 MiB، والنسخة الشاملة حتى 8 MiB؛ يظهر فشل الحفظ ولا يُعلن نجاحًا وهميًا عند تجاوز الحدود.

## تحقق ما بعد النشر المقترح

لم يُنفذ هذا التحقق لأنه يتطلب رابطًا منشورًا: راجع HTTPS والرؤوس وملفات JS/Workers، نفّذ مشروعًا ودرس Vue Router، جرّب الحفظ وإغلاق المتصفح والعودة والنسخة الشاملة، ثم اختبر جوالًا فعليًا وصوتًا فعليًا وصوت النطق المثبت في النظام. لا تُستبدل هذه الخطوة باختبارات Chromium المحلية الموثقة في تقرير القبول.
