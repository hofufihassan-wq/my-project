# معاينة V Lex Pro 1.0 — الموقع الحقيقي

صور PNG من Chromium محلي أثناء تشغيل نسخة الإصدار، بملف مستخدم جديد وبيانات تجريبية فقط. لم تُستخدم صور مولّدة، ولم تُمس بيانات مستخدم حقيقية أو اللقطات المرجعية السابقة. الثيم الزمردي ظاهر في الأقسام، ثم الثيمات الأربعة الأخرى والجوال. بقي تصميم المحاكي مستقلًا.

[تقرير القبول والقيود](../FINAL_AR.md) · [نتائج الاختبارات وبصمات التشغيل](../verification/final/ACCEPTANCE.json)

المعاينة المباشرة جزء من المختبرات والقاموس والمحاكي؛ لم ننشئ صفحة إضافية للتصوير. لقطات المشاريع تُظهر المحرر ونتيجة تنفيذ حقيقية مع مدخلات تجربة. إطارات المعاينة لها تمرير داخلي؛ جرى تمرير بعضها لعرض نتيجة التفاعل. تظل معاينة المشروع التعليمي خاملة بعد التشغيل، وتنفذ أدوات التجربة الأحداث في البيئة المعزولة؛ المحاكي مساحة التفاعل المباشر.

## فيديو الجولة المستمرة

[فتح الفيديو MP4 على GitHub](review.mp4) · [فتح الملف مباشرة أو تنزيله بعد تسجيل الدخول](https://github.com/hofufihassan-wq/my-progect/raw/refs/heads/feat/vlex-v1-followup/docs/v1-completion/preview/review.mp4)

التسجيل متصل من المتصفح الفعلي بتوجيه Playwright، دون قطع أو تسريع أو مونتاج. يبدأ بالرئيسية، ويعرض القاموس والشرح والدروس ومسار Vue وتشغيل Router ومختبري CSS/JS والتدريب والمشاريع الستة والملاحظات والتقويم والمهام والإعدادات والمحاكي والثيمات والجوال، ثم يعود للرئيسية. ملف MP4 بترميز H.264 وyuv420p وfaststart؛ لا يحتوي مسار صوت. اختبارات الصوت منفصلة في تقرير القبول، ولا يمثل الفيديو الصامت تسجيلًا سمعيًا.

**حد التحقق من التسليم المرئي:** فُحصت الصور محليًا وبنية PNG، وفُحص فك الفيديو كاملًا وتنسيقه، وروابط Markdown ووجود ملفات GitHub وبصماتها. لا تتوفر جلسة متصفح مسجلة في المستودع الخاص للتحقق من ظهور الصور أو تشغيل الفيديو داخل واجهة GitHub نفسها؛ لذلك لا ندعي اكتمال شرط العرض داخل GitHub. البديل الآمن للمراجعة هو فتح ملف MP4 أو تنزيله من الرابط الخاص أعلاه بعد تسجيل الدخول، مع الصور المضمنة في هذا التقرير. يبقى اعتماد العرض من حساب المستخدم غير متحقق هنا.

سجل التنقل والتقاط الصور: [capture.json](capture.json). لا نشر للموقع أو دمج في main.
