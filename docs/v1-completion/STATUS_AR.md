## A1: استعادة موضع الاستخدام

أضيف حفظ الصفحة الآمنة الأخيرة وقسم التنظيم ومرشحات المسار والمستوى وتبويب الدروس. تستمر المسودات في المخزن القائم. لا تعاد جلسة تشغيل المحاكي تلقائيًا؛ يبقى استكمال مصدره ضمن آلية المسودات السابقة.

أضيف مؤشر حفظ صغير: جاهز، محفوظ بعد تحقق القراءة/الكتابة، أو فشل. التخزين فوري متزامن، لذلك لا تعرض حالة «جارٍ الحفظ» شكلية. تُتجنب الكتابة عندما لم تتغير البيانات، دون تأخير حفظ أحرف جديدة. لا ادعاء بمحاكاة انقطاع الكهرباء الفعلي.

امتداد المخطط اختياري للنسخ القديمة، والتحقق من الاستيراد يرفض وجهات تنقل أو مرشحات غير معروفة. بقيت آلية النسخ الاحتياطي والحماية الأصلية، ولا توجد مزامنة سحابية.

نتائج هذه الدفعة في platform-tests/v1-completion/A: اختبارات المخزن ومخططه، واستعادة الصفحة والمسار والمستوى والمسودة والثيم بعد إغلاق عملية المتصفح وفتحها، واستعادة تبويب المراجعة، والاستيراد غير الصالح. نجح بناء CSS والتحقق من 27 أصلًا. تعثرت محاولة اختبار أولى بسبب محدد CSS خاطئ للتبويب؛ صُحح محدد الاختبار دون إضعاف شروطه.

## A2: الحفظ الشامل والاسترجاع — منفذ ومختبر

حُفظت مسودات نماذج الملاحظات والمشاريع والمهام والتقويم أثناء الكتابة حتى قبل إرسال النموذج، دون إنشاء سجلات مكتملة وهمية. حُفظ تحرير القاموس منفصلًا عن أمثلته الأصلية، وتلميحات الدروس وموضع المحاكي وأبعاد ألواحه وإخفاؤها. تبقى أكواد المختبرات وArrow والثيم والتقدم في مخازنها السابقة؛ لا يبدأ تشغيل كود تلقائيًا بعد الاستعادة.

أضيف `full-backup.js` وزر تصدير/استيراد شامل في الإعدادات. يجمع الملف المخزن التعليمي والتقدم القديم والمفضلة ومسودات المحاكي وإعدادات الصوت/الحركة/الإكمال والثيم التجريبي. لا تُجمع مفاتيح تطبيقات أخرى أو ملفات اعتماد. يبقى الاستيراد القديم متاحًا. يُتحقق من المخطط والإصدار والحجم قبل التغيير؛ يُحفظ الأصل الخام مع سجل معاملة قبل الاستبدال، ثم تُتحقق الكتابات. الفشل يعيد القيم الأصلية، والاستعادة عند الإقلاع تعالج المعاملة المنقطعة قبل تحميل المكونات. التعارض أو السجل التالف يحمي الأصل ويمنع الكتابات، مع تنزيل ملف استرجاع خام منفصل لا يصلح للاستيراد المباشر.

## B: المحرك المشترك — منفذ ومختبر، والمحتوى ما زال قيد التوسعة

أضيف مسار «دروس HTML وCSS وJavaScript وVue الموجّهة» من صفحة تعلّم معي، بأربع وحدات أولية ذات أهداف ومتطلبات وأمثلة وتمارين مختلفة. يحافظ على مراحل Arrow الثماني وألوانه ومحرر النص الأصلي، ولا يعدّل نموذج Arrow أو محرك المحاكي. لكل درس مسودات ومراحل وتوقع وتلميحات ومحاولات وأسئلة فهم وإتقان ومراجعات وأخطاء محفوظة (آخر 40 خطأ). التقدم آلي من نتائج الكود الحالي والأسئلة؛ تغيير المصدر لا يرث نجاح نسخة قديمة. توجد عودة من المحاكي تحفظ الموضع والمسودة.

التقييم متعدد اللغات في `guided-evaluator.js`: HTML عبر DOM وصلاحية النماذج الأصلية، وCSS عبر computed style وعروض إطار فعلية. لا سكربتات في أداة HTML/CSS. JavaScript في Worker قابل للإنهاء، داخل وسيط iframe مع CSP تمنع الشبكة، وقناة خاصة للنتائج. Vue يستعمل مترجم SFC والعارض المخصص الرسمي لـVue 3.4.21 في Worker نفسه، ويختبر شجرة العناصر والأحداث والتفاعلية وربط المدخل النصي؛ ليس DOM متصفحًا كاملًا. المعاينة لقطة خاملة آمنة بعد التفاعلات. لا ندّعي حاليًا دعم Router أو document أو الحزم الخارجية في التقييم. التقييم هو حالات وظيفية محددة، وليس برهانًا لكل المدخلات أو أمانًا مطلقًا أو حدًا صارمًا للذاكرة.

نتائج `platform-tests/v1-completion/B`: محرك اللغات 14/14، واجهة الدرس والحفظ وإغلاق المتصفح والتنقل والجوال 14/14، مخطط الحالة والإتقان 5/5. انحدار Arrow والتكامل ناجحان، وبناء CSS والتحقق من 27 أصلًا ناجحان. اكتُشف خطأ محرف سطر داخل قالب الواجهة وأُصلح قبل نجاح المسار الكامل. التقارير القديمة لم تُستبدل.

رُوجعت الوحدات الأربع على صفحات MDN: Basic HTML syntax، Basic CSS selectors، Functions، وعلى وثائق Vue: Reactivity Fundamentals وCustom Renderer API. يؤكد مرجع العارض أنه يستهدف بيئات غير DOM، ولذلك أُعلنت هذه الحدود في الواجهة. الروابط المباشرة داخل بيانات كل درس. لا تُسجل الوحدات القديمة الأخرى كمكتملة بسبب إضافة المحرك.
