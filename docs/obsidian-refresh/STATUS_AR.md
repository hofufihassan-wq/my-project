- تنسيق موحد للدروس والمختبرات وشرح الكود والمشاريع والتنظيم والإعدادات. المحاكي يحتفظ بالتشغيل والأصوات وأدواته، مع إطار متناسق ومساحة أوسع وأقل تكرارًا في التنقّل.

تظهر أسباب الخطأ مع رسالتها الأصلية. رقم السطر يعرض فقط لأخطاء صياغة JavaScript عندما يحدده المحلل في المصدر الأصلي؛ لا تُخترع أرقام لأخطاء التنفيذ أو أغلفة Vue. نُقلت مخرجات Console الفعلية إلى موضع واضح قبل المعاينة.

## ما بقي محدودًا

المساعدة التعليمية محلية وليست ذكاءً اصطناعيًا عامًا. الأمثلة التي تحتاجTypeScript أوNuxt أو ملفات ومكتبات أخرى تحتفظ برسالة نطاق الدعم؛ لا نتائج تشغيل مختلقة. مسودات المستخدم وتقدمه محلية على متصفحه، ولا تنشر مع ملفات الموقع. النسخة السابقة الموجودة هنا نسخة من ملفات الموقع، ويمكن حفظ البيانات الشخصية من الإعدادات بالتصدير الشامل.

الاستضافة باقية GitHub Pages من main والجذر، دون خادم تطبيق أو خدمة مدفوعة. الاختبار المنشور القابل لإعادة التشغيل: platform-tests/obsidian-refresh/hosted-browser.cjs --url https://hofufihassan-wq.github.io/my-project/ بعد البناء؛ يقارن كل ملفات التشغيل المنشورة ويختبر CSS وJavaScript وVue والمحرر والتأكيد والحفظ والجوال من الموقع نفسه. لا يفترض ترويساتCloudflare أو نشر manifest الحزمة علىPages.


عند تجهيز النشر أضيف رقم مراجعة لعناوين JavaScript وCSS المعدلة ومحول المعاينة، حتى لا يجمع المتصفح واجهة جديدة مع ملفات تنفيذ قديمة من ذاكرة Pages المؤقتة. هذا لا يغير عنوان الموقع أو أصل التخزين أو مفاتيح بيانات المستخدم. أعيد فحص تحميل الصفحات والمعاينة بعده، وتعاد المجموعات68 كاملة علىGitHub.


كشفت مراجعة أبعاد الرسوم أن قاعدة مقاس الأيقونات كانت تصغّر SVG مخطط المحاكي إلى20×20. قُصرت على أيقونات الواجهة، وبقيت الرسوم التعليمية والمخططات على مقاساتها الأصلية. أضيف فحص أبعاد المخطط إلى مجموعة التصميم لمنع رجوع المشكلة؛ لم يتغير منطق التشغيل أو التقييم.
