# خريطة المحتوى والتكييف

فُحصت بيانات60 درسًا قائمة فعلًا: JavaScript20 وVue18، وHTML10 وCSS12 كمحتوى تأسيسي. لم تُبدّل المعرفات أو تحذف الدروس أو تعاد كتابة تقارير تدقيق المصطلحات. يعرضها النظام الجديد بأربع مراحل مستخدمًا الأمثلة وعقود التقييم الخاصة بكل مهارة؛ الاختبارات الوظيفية الأصلية بقيت كما هي.

## التسلسل والمتطلبات

مسار JavaScript الحالي: القيم والمتغيرات والعمليات، الأنواع، الشروط، الحلقات، الدوال، المصفوفات، الكائنات، map/filter، reduce، الإغلاق، Promises، async والأخطاء، Modules، Debugging، DOM، الأحداث والتفويض، التخزين، Fetch، وتنظيم المشروع. العمليات جزء من الدروس الأولى، وليست صفحة مفقودة. يمكن فتح المتطلبات مباشرة من تفاصيل كل درس؛ لا يلزم TypeScript أوNuxt.

مسار Vue يبدأ بتمهيد للمكوّن والقالب والحالة في ref، ثم الاستيفاء والربط، الأحداث، reactive، computed، الشروط، القوائم، v-model، watch، دورة الحياة، props، emits، slots، composables، model بين المكونات، البيانات غير المتزامنة، Router، وتطبيق تجميعي. أمثلة ref الأولى تحتوي قالب HTML وأحداثًا؛ أضيف شرح مبسط لمعنى المكوّن والحالة، وتبقى روابط HTML والدوال متاحة دون تغيير حفظ المتعلم.

ظهر تعقيد سابق في أول JavaScript: أمثلة تستخدم دوال قبل درس الدوال. عولج مدخل المتغيرات بمقتطفات بيانات مباشرة وعرض بطاقة حقيقية من ناتجها؛ الدروس التالية تحتفظ بدوال البداية الجاهزة وتبدأ بمرحلة تعديل صغير وتشغيل قبل تمرين الكتابة. الدروس المتقدمة لا تطلب مسار مبتدئ مكررًا؛ تعرض تمرينها الأصلي المناسب وعملية إتقانها في المرحلتين الأخيرتين. ليست كل مهارة بحاجة إلى دالة جديدة أو ثلاثة فراغات مصطنعة.

## المشروع المحوري

أضيف11 جزءًا لمدير المهام: مهمة HTML ثابتة، بيانات متغيرات، مصفوفة، إضافة بدالة، حذف بـfilter، حالة منطقية، v-for، v-model، @click، مكونات مع props/emits، ثم حفظ محلي. كل جزء له مصدره ومسودته وتقييمه؛ لا يستبدل المشاريع الستة السابقة. تعرض الواجهة قائمة المراحل والمتطلبات وروابط مراجعتها. النسخة الأخيرة تقرأ وتكتب مخزنًا خاصًا بمشغل الدرس؛ لا يصل كود المتعلم إلى localStorage الأصلي للمنصة.

## الأدلة وحدودها

اختبار التكييف60/60 يثبت أن الأمثلة تعمل في سياق الأداة وأن كل درس يمتلك تمرينًا وتطبيقًا ومخطط حفظ صالحًا. لا يُقدَّم كإعادة تدقيق علمي لكل محتوى القاموس. اختبارات المنهج القديمة تفحص المرجع الصحيح والحلول الخاطئة وعقود DOM/CSS/Vue، وتُعاد في حزمة القبول. للمشروع الجديد44/44 حالة مرجعية/ناقصة، وللنماذج الثلاثة30/30 تشمل بدائل صحيحة وحدود20 والقوائم الفارغة. المراجع الرسمية الموجودة بكل درس بقيت متاحة؛ المساعدة محلية محدودة وليست خدمة ذكاء اصطناعي.
