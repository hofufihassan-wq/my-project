## التشخيص والتعديل

النص CSS كان `.dictionary-tech-mark` داخل `.dictionary-title-row` في index.html، بعرض ثابت 43px وخط 30px. كان عنصرًا زخرفيًا باسم فئة المصطلح، لا لغة الملف المفتوح. أزلنا العنصر الزخرفي، وأضفنا علامة صغيرة إلى `.dictionary-editor-formats` بجانب اسم الملف، مرتبطة بـactiveCodeFormat وفئة المثال. تبديل Vue يغيرها إلى Vue وExample.vue، والعودة إلى مثال CSS تعرض CSS وstyles.css. بقي التصنيف في breadcrumb والتصفية؛ لم نحذف وظيفة.

أشرطة الملفات المشتركة تعرض metadata واضحة داخل واجهة داكنة متناسقة، مع شارات صغيرة وحدود خفيفة، على القاموس والدروس ومختبري HTML/CSS وJavaScript والشرح. أسماء source/lesson/project تمثل عنوان مساحة التحرير داخل التطبيق، وليست ادعاء بوجود ملفات مستقلة محفوظة على القرص. دروس HTML المركبة تبقى HTML حتى لو تضمنت Vue بداخلها. استُخدمت CSS وmarkup فقط، دون مكتبة محرر جديدة.

ألوان النصوص الثانوية أكثر هدوءًا، والذهبي محدود في الشارات والحالات النشطة بدل كل أزرار القاموس. قللنا هوامش الشرح ونموذج المشاريع، وحصرنا تغيير النموذج في `.vlp-project-form` حتى لا نغيّر نماذج الملاحظات والمهام. لا عناصر إحصائية أو زخرفية مضافة لملء الفراغ.
