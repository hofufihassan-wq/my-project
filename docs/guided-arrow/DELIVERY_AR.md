# تسليم نموذج الدوال السهمية للمراجعة

10 نوفمبر 2026 UTC — فرع `feat/vlex-guided-arrow`. أساس التصميم a3a464b9، مع تقرير الاستعادة 587492b. اعتمد المستخدم استمرار العمل دون انتظار 89e91a؛ لا تُنسب إليه أي إصلاحات جديدة.

## ما نُفّذ

نموذج واحد ذو ثماني مراحل: شرح عربي فصيح وأهداف ومتطلبات سابقة، شروح معدة مسبقًا للأسطر والرموز قابلة للنقر ولوحة المفاتيح، توقع بنتيجة وتلميحات تدريجية، محرر وتشغيل فعلي، كتابة حل وتصحيح خطأ، تحقق سلوكي، اختبار إتقان، وحفظ ومراجعة وخطوة تالية من الدروس الموجودة.

التمارين الأساسية: double ثم إصلاح square ثم كتابة add في الإتقان؛ filter توسعة اختيارية بعد المصفوفات. لا يوجد عرض حل كامل تلقائي. يميز المصحح شرط كتابة الصيغة السهمية بنيويًا عن الاختبارات الوظيفية، ويقبل الإرجاع الضمني والصريح والمعاملات المسماة بصيغ مختلفة والدوال المساعدة ضمن نطاقه. اختبارات القيم تشمل الموجب والصفر والسالب والكسور؛ وfilter تشمل الفراغ والتكرار والسالب والصفر وعدم تعديل المصفوفة الأصلية.

الحفظ في قسم guidedArrow مستقل داخل مخزن التعلم الحالي: المرحلة والتمرين المختار والمسودات والإجابات والتلميحات وعدد محاولات التقييم ونسخة المصدر التي اجتازت وموعد المراجعة. تعديل المصدر يبطل اعتبار نجاحه السابق دليلًا على النسخة الجديدة. كتابة الدروس القديمة لا تسقط بيانات النموذج. النسخ القديمة تستورد مع حالة ابتدائية للنموذج؛ رفض الاستيراد غير الصالح لا يمس الأصل.

زر «جرّب في المحاكي» يحفظ ثم يرسل سياق HTML/JavaScript للمصدر المدعوم إلى المثال المرجعي الموجود دون تشغيل تلقائي، مع زر عودة صريح. لم نعد بناء المحاكي أو نغير ألوانه أو مصادر الصوت. تبقى جميع المساحات القديمة متاحة.

## الدفعات

- `f7f9091`: تصحيح وصف معاملات السهمية وتحذيرها، مع توثيق المراجعة المركزة. لا تعديل لمصادر أمثلة القاموس أو بصماتها أو تصنيفاتها.
- `def08a6`: محتوى النموذج، مخطط الحفظ المتوافق، المقيم الوظيفي واختبارات الوحدة.
- `141f033`: واجهة المراحل والتلميحات والإتقان والنقل والحفظ، وفحوص المتصفح والانحدار وأدلتها.
- دفعة التسليم الختامية تضيف هذا التقرير وتعليمات المعاينة، وتستخدم أسماء ملفات تقارير صالحة على Windows (دون النقطتين الرأسيتين في أسماء الملفات).

فحص المتصفح يشمل الحلول الصحيحة المختلفة والخاطئة والثابتة والإرجاع المفقود والمهلة والتزوير وXSS والتلميحات والتنقل والعودة من المحاكي واستيراد البيانات. اختبار الاستعادة يغلق **عملية المتصفح** ذات ملف المستخدم الدائم ويفتح عملية جديدة ثم يفحص المرحلة والمسودة والتلميحات ودليل الإتقان؛ ليس مجرد إعادة تحميل الصفحة.

حُفظت نتائج المحاولة الأولى للمصفوفة: 27/30. فشل اختبارا البيانات القديمان لأن بيئتهما المختزلة لا تحتوي location؛ عولج الوصول الاختياري إلى location/history دون إضعاف الاختبارات، ونجحا بعد الإصلاح (15/15 و9/9 تأكيدات). فشلت ثلاث قياسات viewport في مجموعة CSS تحت تشغيل المتصفحات المتوازي. ملف CSS الناتج مطابق للأصل بايتًا ببايت، واجتازت المجموعة الأصلية منفردة 25/25 دون تغيير شروطها. هذه ملاحظة موثوقية اختبار عند التوازي، وليست سببًا لإخفاء النتائج الأولى أو ادعاء عدم وجود أي تعثر.

لم تُعد مراجعة المصطلحات الـ180 والمصادر الـ360 كاملة. تبقى تقاريرها السابقة، وتصنيفات النسخة المعتمدة 86/220/54؛ ليست استعادة لأرقام الدفعة المفقودة. فحص preservation في المصفوفة يؤكد بقاء المعرفات ومصادر الأمثلة والنسخ الأصلية وفق قائمة التصحيحات التاريخية.

## حدود التشغيل والأمان

التجربة الحرة تستخدم مشغّل Worker القائم داخل iframe معزول. المقيم يستخدم Worker منفصلًا قابلًا للإنهاء خلال 1500ms، مع CSP يمنع الشبكة وقناة MessageChannel خاصة، والتحقق من نافذة الإطار والجلسة وبنية وحجم الرسائل. لا تنفيذ لكود الطالب في واجهة التطبيق. يحلل المقيم نطاقًا محدودًا من JavaScript لدوال عددية ومصفوفات متزامنة، ويرفض الاستيراد وواجهات البيئة والولوج العام للخصائص. اجتياز الحالات دليل محدود على هذه المتطلبات، وليس برهانًا عامًا أو اعتمادًا أمنيًا لتشغيل كل مصدر عدائي.

المحاكي القديم يبقى ضمن حدوده السابقة؛ iframe وحده لا يضمن منع تجميد كل مصدر متزامن. يرفض زر نقل النموذج الحلقات وواجهات البيئة المعروفة خارج سياقه المدعوم، لكنه ليس محلل إنهاء شاملًا لأي JavaScript. لا ندعي اختبار Windows أو المتصفحات الأخرى أو النطق البشري.

## المعاينة

راجع [تعليمات المعاينة المرفقة بالحزمة](../../ARROW_PILOT_PREVIEW_AR.md). من المستودع: `python3 scripts/start-local.py --no-browser` ثم `http://127.0.0.1:8091/#arrow-functions`. أو افتح «تعلّم معي» ثم زر نموذج الدوال السهمية. المراحل مفتوحة للمراجعة، ولا يعد تجاوز مرحلة اجتيازًا.

أُعدت حزمة محلية قابلة للتنزيل خارج المستودع للفحص فقط. ملفات الحزمة المولدة ليست منشورة. لا merge في main ولا push ولا خدمات مدفوعة. بقية المناهج لم تُوسع؛ ننتظر مراجعة هذا النموذج واعتماده قبل التعميم.
