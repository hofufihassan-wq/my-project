# مراجعة مركزة قبل النموذج

اعتمد المستخدم في 10 نوفمبر 2026 نسخة التصميم a3a464b9 وتقاريرها، دون انتظار الدفعة المفقودة. هذا الملف إضافة إلى التقارير السابقة ولا يستبدلها.

- راجعت مخاطر المحرك والتخزين والفجوات التعليمية وتقارير الاستعادة. لم يظهر مانع جديد مثبت في فحوص الاستعادة الثلاثين يستلزم إعادة بناء المحاكي أو إعادة تدقيق 360 مثالًا.
- أصلحت في مدخل Arrow Function تسمية المعاملات التي كانت `arguments`، والتحذير العام الذي أوحى بأن فحص null شرط خاص لاستدعاء الدوال السهمية. الوصف الجديد يوضح this وarguments المعجميين وحدود new والإرجاع الصريح وإرجاع الكائن.
- لم أعدل مصدر أي مثال بالقاموس أو أنقل تصنيفه إلى «يعمل». مثال السهمية القديم يعرض نجاحًا شكليًا؛ يبقى «يحتاج سياقًا» مع السبب الموجود. لا نستخدمه دليل صحة في النموذج الجديد.
- يبقى 220 مصدرًا يحتاج سياقًا و54 خارج الدعم، وليسا أخطاء مثبتة تلقائيًا. لا ادعاء باستعادة إصلاحات 89e91a.
- المحاكي الحالي iframe مع صلاحيات محدودة لكنه لا يضمن إيقاف كل حلقة متزامنة. النموذج يستخدم Worker قابلًا للإنهاء، ويمنع إرسال حلقات ومصادر خارج نطاق التمارين المدعوم إلى المحاكي. لا نعيد بناء المحاكي.
- الحفظ المحلي ليس مزامنة حسابات، ويحتاج تصديرًا عند تغيير العنوان. اختبارات Windows والنطق البشري خارج نتائج هذه الجولة.

المراجع: MDN Arrow function expressions وWorker.terminate، وروابط التقارير في docs/recovery. راجعنا سلوك الإرجاع والمعاملات وthis/new في وثيقة MDN عند إعداد النموذج واختباراته؛ فحص المثال البرمجي الفعلي موثق في دفعة النموذج.
